## 1. 本轮先修的两个阻塞问题

### 1.1 LDO/scaffold 未见药物无法评估

`fit_stats/.../label_scaler.parquet` 只含训练 fold 的药物；LDO/scaffold 的
val/test 药物不在其中，原逻辑会把 `y` 设为 0、`label_mask=False`，导致：

- val 指标全为 NaN，早停失效；
- test 无法计算任何指标；
- 之前没有 LDO/scaffold 结果，根因就在这里。

修复（`data/pairs.py`、`data/dataset.py`）：

- 用**训练 fold 的全局 mean/std/median** 作为未见药物的 fallback；
- 逐药 SCC/PCC 对逐药单调变换不变，因此仍是干净的主指标；
- 只使用 train 标签，不泄漏 val/test；
- 新增 `tests/test_label_fallback.py`。

验证：`p2_ldo_s0` / `p3_scaffold_s0` 的 val/test `label_mask` 全部为 True，
`y` 非零，per-drug SCC 可计算。

### 1.2 无靶点药物让 target 分支产生 NaN

49/286 个药物没有靶点（LDO test 中 10/57，scaffold 中 15/58）。`TargetGeneEncoder`
把全 False 的 `target_gene_mask` 直接传给 `TransformerEncoder`，全 `-inf`
attention 产生 NaN；`target_gate != 0` 时污染输出。

修复（`models/teacher/t0.py`）：对全 mask 的行跳过 encoder，输出 0 token，
`target_valid=False`。验证 P1/T1 前向不再出现 NaN。

## 2. T1 实现

### 2.1 图构建（`src/kite_drp/train/t1_graph.py`）

| 项 | 实测（`p2_ldo_s0` fold0） |
|---|---|
| 基因空间 | targets ∪ HVG top1000 ∪ top500 突变 → **2,770 基因** |
| PPI | STRING ≥700 诱导子图，双向 **49,402 条有向边**（约 24.7k 无向边） |
| DTI | gene → drug，4,395 条 |
| cell-gene | gene → cell，top10% 表达 + 全部突变，**213,403 条** |
| 细胞特征 | 3×1000 通路分数 + 3 个 mask = 3,003 维 |
| 药物特征 | Morgan 2048；靶点表 cap 64（target 分支）+ 全靶点表（药物编码器） |

- 缓存：`data/interim/teacher/t1_graph/<split>/fold<k>/graph.npz` + `graph_spec.json`；
- 随机对照：`rewire=ppi|dti|cg`（度保持双边交换）；去边：`edge_drop=...`；
- 构建与缓存已用 5 种对照配置验证，边数/哈希符合预期。

### 2.2 模型（`src/kite_drp/models/teacher/t1.py`）

```text
P1 gene embedding 表子集 → G0（2,770×16）
G0 + 基因统计 → PPI-GNN（2 层）→ H（128）
G = G0 + tanh(α)·W(H)                 # α 初始 0
target 分支：G[targets] + 细胞值       # 与 P1 共享同一份图基因嵌入
药物编码：mean(G[全部靶点]) + Morgan

h_drug = DTI-GNN(H, drug_init)        # gene → drug
h_cell = CG-GNN(H, cell_init)         # gene → cell
z_cell = z_cell_P1 + tanh(β)·proj(h_cell)
z_drug = z_drug_P1 + tanh(γ)·proj(h_drug)
y_fused = heads(z_drug + z_cell)
y_graph = graph_head([h_drug,h_cell,h_drug⊙h_cell])   # 深监督
```

- 参数：**6,097,099**（backbone 4,595,526 + graph 1,501,573），`params_target=7M`；
- 初始化：从同 fold P1 checkpoint 加载 backbone + 基因表子集；三个 gate=0；
- 已验证 **T1 初始化时与 P1 数值等价**（合成单测 + 真实 LDO batch，max |Δy| ~1e-7）；
- `gene_out_proj` 不零初始化，否则 `gene_gate` 在 0 点梯度恒为 0，PPI 知识无法进入
  target 分支；`gene_stats_proj` 零初始化保证起点等于 P1。

## 3. 耗时实测（本机，RTX 4060 Ti 级别）

| 模型 | 每 epoch（含 val） | 2 折 × 2 seeds × 20 epochs |
|---|---:|---:|
| P1 LDO | **~47 s** | ~1.0–1.3 h（早停后更短） |
| T1 LDO（2 epoch smoke） | **~100 s** | **~3.3 h**（3 折 × 2 seeds） |

结论：T1 快速筛选远低于 48 h，本机可跑；正式 5 折 × 3 seeds 预计 8–12 h。

## 4. 复现命令

```bash
# P1 LDO：3 折 × 2 seeds
uv run python scripts/run_t1_quick.py --variants p1 --split ldo \
  --folds 0,1,2 --seeds 0,1 --epochs 20 --out experiments/p1_ldo_quick

# T1 快速筛选：P1 + T1 + 随机 PPI/DTI
uv run python scripts/run_t1_quick.py --variants p1,t1,t1_random_ppi,t1_random_dti \
  --split ldo --folds 0,1,2 --seeds 0,1 --epochs 20 \
  --init-from experiments/p1_ldo_quick --out experiments/t1_ldo_quick
```
