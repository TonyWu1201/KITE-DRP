# PPI/DTI 先验学习与 T2 改进调研（2026-11-23）

- 目的：回答“是否有药敏预测模型真正从 PPI/DTI 中**学习**生物学先验”，并据此给出 T2 的改进方案。
- 范围：细胞系药敏（GDSC/CCLE 类 IC50/AUC）、药物扰动响应、PPI/DTI 表征学习；不重复上一份调研已覆盖的 TGSA/DRPreter/PathGuard 细节，重点补充 2023–2026 的传播、辅助任务、预训练与动态图工作。
- 证据等级：A = 严格 cold-drug/scaffold-cold + 随机图/均值对照；B = cold-drug 但缺少随机图或强基线；C = warm/cold-cell 或不同端点（扰动响应、靶点排序）；D = 预印本/早期结果。所有结论均注明原论文协议，不替代本项目预注册实验。

## 0. 结论摘要

1. **有，而且不止一类做法。** 文献里“从 PPI/DTI 学习先验”至少有五种形态：
   - 先验当输入（PPI/DTI 图或固定特征）；
   - 先验当架构约束（PPI 约束 attention、visible neural network、异质图）；
   - 先验当辅助监督（DTI link prediction、RNA/通路辅助任务）；
   - 先验当干预/传播（从靶点在 PPI 上传播，选“间接靶点”）；
   - 先验当特权信息（teacher 用 PPI/DTI，student 不用，靠蒸馏迁移）。
2. **真正能在 strict cold-drug 下稳定涨点的，主要是“传播”和“辅助任务”，不是“再加一个静态 PPI 分支”。**
   - **NetGP / DGDRP**：从 DTI 靶点出发在 STRING 上迭代传播 + 通路富集，得到每药“间接靶点”profile，再拼到任意 DRP 模型；64/72 组比较提升，unseen-drug 的 PCC 最高 +34%。[NetGP2023, DGDRP2024]
   - **CSG²A**：把 STRING PPI 作为 condition-specific gene–gene attention 的先验，并在 LINCS L1000 上预训练；GDSC cold-drug RMSE 2.119、PCC 0.611，优于 DeepTTA 的 2.322/0.502。[CSG2A2024]
   - **KGDRP**：BioHG（PPI + DTI + GO + Reactome）+ RNA/DTI/生物过程三个辅助预测器；cold-drug SCC 0.556；去掉 DTI 辅助任务后降到 0.411，是三个辅助任务里影响最大的。[KGDRP2025]
   - **DTLCDR**：不直接用实验 DTI，而是用 DTI 预测器生成“target profile”，再与单细胞语言模型融合；unseen-drug 泛化提升，ablation 显示 target 信息贡献最大。[DTLCDR2025]
3. **但先验不是免费午餐，最强的反证同样来自 2025–2026。**
   - **XPert** 的知识异质图（含 PPI/DTI）在 cold-drug 上只把 xdeg PCC 从 0.637 提到 0.640、RMSE 从 0.549 降到 0.545；作者自己写“HG contributes only incremental or partially redundant information”。[XPert2026]
   - **Pillbox** 用 STRING PPI GAT + CpGPT/CLAMP foundation embedding；curated mutation、methylation、drug-target-expression 通道在 foundation embedding 之后都不再提升，lineage 仍是主导。[Pillbox2026]
   - **DrEval / Tran & Klau** 的严格评测里，图/PPI 的增益在 LDO 下普遍消失，甚至低于 drug-mean。[DrEval2026, Tran2026]
4. **当前 T2 的问题不是“没有 PPI/DTI”，而是“先验被 P1 覆盖 + 固定特征不可学习 + 根节点主导 + 覆盖不足”。**
   - 本仓库实测：T2 的 `rwr` 特征与 `root` 集合统计的相关系数为 **GE 0.963 / MU 0.991 / CNV 0.984**（213 个有 DTI 的药 × 716 个细胞系）。RWR 实际上退化成“靶点表达的平滑版”，而 P1 的 target branch 已经在读同一组靶点基因值。
   - T2 遮挡实验（OT 子集，22 药）：`zero_summary` −0.0026、`zero_all` −0.0019、`zero_rwr` −0.00036、`zero_pathway` −0.00031。真正被模型使用的只有 summary；RWR/pathway 几乎不贡献。
   - DTI 覆盖 213/286（74.5%），其中 OT 104、GDSC-only 109、无 DTI 73；97 个药是单靶点，局部图拓扑几乎固定。当前 DTI 还是二值、无方向，浪费了 `action_type`（418 条 INHIBITOR、3 条 AGONIST、1 条 DEGRADER 等）。
5. **建议的改进路线（按性价比排序）：**
   - **M0**：先修融合 gate。当前 α≈0.137 明显低估第二塔；fold0 的 `t2_base` fixed 0.5 为 0.6175、`t2_all` 为 0.6196，均高于学习 gate 的 0.6121。零成本，先做。
   - **M1**：用 NetGP 式“间接靶点传播”替换当前 RWR；排除直接靶点，保留 gene-level 表达读出；加通路富集再播种。
   - **M2**：做 DTI 补全（drug fingerprint → target profile），覆盖 73 个无 DTI 药，并把二值 DTI 升级为 soft target profile。
   - **M3**：加 DTI 辅助预测头（KGDRP-lite），让第二塔在训练时被迫编码 target 生物学，而不是只记 drug ID。
   - **M4**：用 PPI GraphMAE 预训练 gene token / pathway token，把 PPI 结构学进表征，而不是塞进主路径。
   - **M5**：在 gene/drug 表征上加 PPI Laplacian + DTI alignment 正则（低成本，但可能与 target branch 冗余，需严格对照）。
   - **M6**：如果 M1–M3 有正信号，再做 cell-specific PPI（表达加权/共表达）或 PINNACLE 式 contextualized protein embedding。
   - **M7**：长线才考虑 CSG²A/XPert 式 PPI-biased attention + LINCS L1000 预训练（需要新数据，成本高）。
   - **M8**：把 PPI/DTI 当 teacher 的特权信息，蒸馏给只输入 panel mutation + expression 的 edge student。这可能是本项目最有辨识度的用法：部署端不需要 PPI/DTI，但学生能继承教师的通路级去噪。
6. **止损规则**：若 M1–M3 在 3 折 × 2 seeds 的 LDO 上做不到“OT 子集逐药 SCC ≥ +0.005 且配对 95% CI 下限 > 0”，或真实 PPI/DTI 打不过保度重连/靶点置换对照的 80% 增益，就停止“再加先验”的主线；转做特权信息蒸馏或靶点排序/机制解释，不再堆图分支。

## 1. 什么叫“从 PPI/DTI 学习先验”

“用 PPI/DTI”与“从 PPI/DTI 学习”不是一回事。按干预深度可分五级：

| 形态 | 典型做法 | 代表工作 | 是否真的“学习” | 对本项目的含义 |
|---|---|---|---|---|
| **L0 先验当输入** | PPI/DTI 图、RWR、邻居统计、pathway profile 作为固定特征 | TGSA、DRPreter、T2 | 部分：只学下游头 | 最容易做，也最容易冗余；T2 已在此层 |
| **L1 先验当架构约束** | PPI 约束 gene–gene attention；gene→protein→pathway→drug 的 visible NN；异质图消息传递 | CSG²A、BKDRP、KGDRP | 是：计算图被先验塑形 | 需要改模型结构，仍可能被强基线追平；BKDRP 严格说是 pathway hierarchy 先验，不是 PPI/DTI |
| **L2 先验当辅助监督** | DTI link prediction、PPI link prediction、RNA/通路辅助任务、masked graph modeling | KGDRP、GraphMAE、PINNACLE | 是：先验进入损失函数 | 成本低、可解释；最适合在 T2 上加 |
| **L3 先验当干预/传播** | 从靶点播种，在 PPI 上传播，选“间接靶点”，再用这些基因的表达预测药敏 | NetGP、DGDRP、DGP-LA、PDGrapher | 是：先验决定“看哪些基因” | 最直接针对 cold-drug；与本项目“局部图”最接近 |
| **L4 先验当特权信息** | teacher 用 PPI/DTI，student 不用；蒸馏 soft label / pathway 表征 | 本项目可做；KD 文献 | 是：先验通过教师迁移 | 与端侧目标最契合；目前文献少，差异化空间大 |

**关键判断**：T2 目前是 L0。L0 的天花板很低，因为 P1 的 target branch 已经读取了直接靶点的 GE/CNV/MU；如果 PPI 特征再退化成 target expression 的平滑版，增量必然接近 0。要改进，必须把先验推进到 L2/L3，而不是继续调 L0 的池化方式。

## 2. 文献证据

### 2.1 NetGP / DGDRP：从 DTI 靶点传播出“间接靶点”

**NetGP（Pak et al., Brief Bioinform 2023）** 是目前与本项目最直接相关的正面证据。

- 输入：药物已知靶点（DTI）+ STRING PPI + 细胞系表达。
- 做法：
  1. 以直接靶点为种子，在 STRING 上做 network propagation；
  2. 对 top 200 基因做通路富集，把富集通路里的基因并回种子，再传播；
  3. 迭代到 top 200 稳定，得到每药的 gene perturbation profile；
  4. 用 MLP 把 profile 编码成固定向量，与 drug/cell 表征拼接；对原 DRP 模型是 model-agnostic 的。
- 结果：在 6 个 DRP 模型、多种 split 上，64/72 组比较提升；unseen-drug 场景 PCC 最高 +34%。[NetGP2023]
- 关键点：**它没有训练一个 PPI GNN，也没有把 PPI 当主路径；它把 DTI/PPI 变成“药物特异的基因选择”，再用这些基因的细胞表达做预测。** 这与 T2 的 RWR 加权和完全不同：RWR 是“给所有基因一个权重然后加权平均”，NetGP 是“选出非直接靶点的间接靶点，再读它们的表达”。
- 局限：test drug 的 DTI 在推理时可用；没有保度重连 PPI 对照；路径富集依赖通路库；不同数据版本可能影响复现。

**DGDRP（Pak et al., Front Genet 2024）** 在 NetGP 上再加一层可学习重排：

- 先用 NetGP 选 top-k 间接靶点，构建 drug-specific 异质图（靶点 + 通路 + PPI 边）；
- 用 GAT + Top-k pooling 得到 drug mechanism embedding；
- 再用 gene embedding 与 drug mechanism embedding 的相似度重排基因，选 top-100；
- 用选中基因的表达 + 药物结构预测 IC50。
- 结果：drug-split 下优于其他 gene selection 方法，与 SOTA 可比；选出的基因与 MoA 对齐。[DGDRP2024]
- 对本项目：**“先传播选基因，再学习重排”** 是一个可复制的中间路线；不必一上来做端到端 GNN。

**证据等级：B。** 正面且直接，但缺随机图对照，且 test drug DTI 可用。

### 2.2 CSG²A：PPI 约束的 condition-specific gene–gene attention + L1000 预训练

**CSG²A（Bang et al., Bioinformatics 2024）** 把 PPI 变成 attention 的先验，而不是后处理特征。

- 输入：药物结构（MAT 预训练）、剂量、时间、细胞基础表达。
- 核心：把基因作为 token，做 condition-specific self-attention；attention 矩阵与 STRING PPI 邻接相加，得到 condition-specific gene–gene 交互权重，作为下游网络的参数。
- 预训练：在 LINCS L1000 上预测药物扰动后的表达谱；再冻结 CSG²A、只训一个 scaling layer 迁移到 GDSC IC50。
- 结果：GDSC 四种 split 均为 SOTA；cold-drug RMSE 2.119 ± 0.397、PCC 0.611 ± 0.140；次优 DeepTTA 为 2.322 ± 0.496 / 0.502 ± 0.198。[CSG2A2024]
- 关键点：**PPI 不是固定特征，而是 attention 的 bias/mask；模型学的是“在当前药物和细胞条件下，哪些 gene–gene 交互被激活”。** 这比静态 RWR 更接近“condition-specific rewiring”。
- 局限：需要 LINCS L1000（本项目没有）；PPI 仍是全局静态；没有保度重连对照；cold-drug 的 test drug 仍有结构和剂量信息。

**证据等级：B。** cold-drug 结果强，但依赖外部预训练数据，且缺随机图对照。

### 2.3 KGDRP：BioHG + 三个辅助预测器

**KGDRP（Ye et al., Adv Sci 2025）** 是“先验当辅助监督”的代表。

- BioHG：Drug–Protein（DTI）、Protein–Protein（PPI，BioKG）、Protein–Pathway（Reactome）、Protein–GO、Protein–Cell line（GDSC RNA 表达）。
- 三个辅助预测器：
  - RNA expression predictor（细胞系表达，比较任务）；
  - DTI predictor（药物–靶点）；
  - biological process predictor（protein–pathway/GO）。
- 主任务：把 IC50 回归改成“drug A–cell–drug B”的比较/分类任务，降低对绝对标签的依赖。
- 结果（GDSC）：
  - cold-drug SCC **0.556 ± 0.115**；NetGP 0.468 ± 0.083、MLP 0.380 ± 0.129；
  - cold-both SCC **0.543 ± 0.075**；NetGP 0.412 ± 0.130；
  - 去掉辅助任务：`noDTI` cold-drug SCC **0.411 ± 0.128**、`noRNA` 0.430 ± 0.105、`noBP` 0.433 ± 0.128。[KGDRP2025]
- 关键点：**DTI 辅助任务是三个里影响最大的**；它让 drug/protein 表征在训练时必须编码“药物结合谁”，从而在 cold-drug 下仍能通过 target 生物学泛化。
- 局限：BioHG 很大（7,070 drug / 117,841 protein / 21,178 pathway），训练成本高；test drug 的 DTI 是否在图中/是否完全屏蔽未明确；没有保度重连/随机标签对照；cold-drug 的绝对值仍不高。

**证据等级：B。** 辅助任务的 ablation 很有说服力，但图规模和评测控制不足。

### 2.4 DTLCDR：用 DTI 预测器生成 target profile

**DTLCDR（Yu et al., J Pharm Anal 2025）** 解决“没有实验 DTI 怎么办”。

- 输入：药物化学描述符 + 分子图 + **DTI 预测器生成的 target profile** + 细胞系表达 + 单细胞语言模型的一般知识。
- 关键：不是只用已知 DTI 的二值边，而是用 well-trained DTI 模型给每个药生成 target profile；这样没有实验 DTI 的药也能有 target 表征。
- 结果：unseen-drug 的泛化和鲁棒性优于 SOTA；ablation 显示 target 信息对泛化贡献最大；并用 in vitro 实验验证了新分子。[DTLCDR2025]
- 对本项目：**73/286 无 DTI 的药是 T2 的硬缺口；DTI 补全比“零填充 + coverage gate”更有信息量。** 但 DTI 预测器必须在 drug-level split 下评估，避免用 test drug 的 DTI 标签训练。
- 局限：DTI 预测器质量决定上限；target profile 仍是二值/概率，不含 affinity/efficacy；没有 strict cold-drug 的随机对照。

**证据等级：B/C。** 方法方向强，但评测协议与 IC50 cold-drug 不完全一致。

### 2.5 DGP-LA：动态图先验 + gated latent correction

**DGP-LA（Bie et al., Bioinformatics 2026）** 不是 IC50 模型，但它的设计非常适合借鉴。

- 任务：单细胞扰动响应预测；输入 control expression + perturbation identity/dose；输出 perturbed expression。
- 做法：
  1. cell-state-conditioned transition backbone；
  2. 用 PPI + DTI 构建 perturbation-specific 的稀疏图，并对图做 refinement；
  3. 把 gene-aligned target support 在 refined graph 上传播；
  4. 把传播结果作为 **gated latent correction** 注入 hidden representation，而不是当输入特征。
- 结果：unseen cell type 的 Pearson Delta 比 State 提升 8.7%/35.8%；zero-shot drug perturbation 比 CRISP 提升 79.1%/67.6%；DE gene 和 Hallmark pathway recovery 也改善。[DGP-LA2026]
- 关键点：**先验影响的是 latent state，而不是输出端的固定特征；并且 gate 由 perturbation-specific target support 决定。** 这正好对应 T2 的 `context_scale` 太弱、`coverage` gate 太粗的问题。
- 局限：端点是 perturbation response，不是 IC50；数据是 Tahoe/NeurIPS 单细胞，不是 GDSC；不能直接比较数字。

**证据等级：C。** 设计参考价值高，任务不同。

### 2.6 PINNACLE / GraphMAE：把 PPI 学进表征

**PINNACLE（Li et al., Nat Methods 2024）** 用 self-supervised link prediction 在 context-specific PPI 上学习 protein representation：

- 输入：多器官单细胞图谱 + 参考 PPI + cell type communication network + tissue hierarchy；
- 输出：156 个 cell type context 下的 394,760 个 protein representation；
- 训练：protein/cell type/tissue 三个层级的 self-supervised link prediction；
- 应用：protein–protein interaction、drug effects across cell types、target nomination。[PINNACLE2024]
- 对本项目：**不是直接做 IC50，但证明“PPI + 自监督”可以产生 context-specific protein embedding。** 如果能把 cell line 当作 context，用 CCLE/DepMap 表达构建 context-specific PPI，再预训练 gene/protein embedding，可能比静态 RWR 更有信息。
- 局限：PINNACLE 训练在健康单细胞图谱上，不是癌细胞系；直接迁移未必有效；成本高。

**GraphMAE** 是更轻的替代：在 STRING 上做 masked feature reconstruction，得到 gene embedding。XPert 的 gene token 就是用 CellML 的 GraphMAE PPI embedding 初始化的；同类 cell representation 工作也采用 PPI GraphMAE 初始化 gene embedding。[XPert2026]

**证据等级：C。** 方法学支持强，但缺少“在 GDSC LDO 上直接涨点”的证据。

### 2.7 反证：先验很容易被强表征/强基线吸收

**XPert（Guo et al., Nat Mach Intell 2026）** 是一个很好的“冷静剂”：

- 任务：L1000 药物扰动响应；模型：dual-branch transformer + UniMol + 知识异质图（DTI/PPI/结构相似性）+ dose/time token。
- cold-drug xdeg：
  - XPert：RMSE 0.545 ± 0.006、PCC 0.640 ± 0.002；
  - XPert w/o HG：RMSE 0.549 ± 0.007、PCC 0.637 ± 0.003；
  - warm：0.518/0.667 vs 0.518/0.667（几乎完全一样）。
- 作者结论：HG 对 XPert 只是 incremental/partially redundant；但对 VAE 类 TranSiGen 帮助更大（warm-start 平均指标提升约 8.05%）。[XPert2026]
- 含义：**当主架构已经很强、细胞表征已经很充分时，PPI/DTI 先验的边际贡献可能只有 0.003 PCC。** 这与 T2 的 +0.001 是同一量级。

**Pillbox（Hill et al., bioRxiv 2026）**：

- 模型：CpGPT methylation embedding + CLAMP drug embedding + per-fold PCA expression + FiLM-conditioned GAT on STRING v12 PPI；
- 结果：random/histology-blind/site-blind R² 0.78/0.77/0.76；lineage 仍是主导；
- 负结果：curated mutation、methylation、drug-target-expression 通道在 foundation embedding 之后都不再提升；跨架构 residual correlation 显示 headroom 只有 ~0.03。[Pillbox2026]
- 含义：**“再加一个 biology channel”在强 foundation embedding 下经常没有增量；先验的价值取决于它是否提供 foundation embedding 没有的、sample-specific 的信息。**

**DrEval / Tran & Klau**：

- DrEval 用统一调参、naive mean effects、树基线、保度边打乱等控制，发现复杂模型在 LDO 下常接近或落后于简单基线；图收益在随机图下可复现。[DrEval2026]
- Tran & Klau 的独立复现里，TGSA 在 LDO 的 RMSE 2.538 ± 0.280，mean predictor 2.536 ± 0.242；作者明确写 PPI 没有改善预测。[Tran2026]
- 含义：**如果不在 LDO/scaffold-cold 下做随机图对照，很容易把“第二套编码/集成”误归因给 PPI 拓扑。**

## 3. 当前 T2 的诊断

### 3.1 结构回顾

T2 = 冻结 P1 + 独立第二塔 + DTI/PPI 固定特征（summary + RWR + pathway）+ 预测级 gate。

- P1 已有 `target_branch`：按药物靶点读取对应基因的 GE/MU/CNV，并编码成 target token。
- T2 的 `summary` 包含 root/neighbor × GE/MU/CNV 的 mean/max/min/std/obs/altered 统计。
- T2 的 `rwr` 是从靶点出发的 personalized PageRank 权重，再与 GE/MU/CNV 加权。
- T2 的 `pathway` 是 target/neighbor 在 1000 条通路上的 profile，与细胞通路分数逐元素相乘。

### 3.2 实测诊断

| 诊断 | 结果 | 含义 |
|---|---|---|
| RWR vs root summary 相关 | GE 0.9633 / MU 0.9912 / CNV 0.9839 | RWR 基本是 root 的平滑版；P1 target branch 已覆盖 |
| T2 遮挡（OT 子集，22 药） | `zero_summary` −0.00263；`zero_all` −0.00188；`zero_rwr` −0.00036；`zero_pathway` −0.00031 | 只有 summary 被用；RWR/pathway 几乎不贡献 |
| T2 融合系数 | α≈0.137；final 0.6121、P1 0.6065、T2 alone 0.6144 | 第二塔本身有效；PPI 增量很小 |
| DTI 覆盖 | 213/286（74.5%）；OT 104、GDSC-only 109、none 73 | 1/4 药物没有先验；覆盖组内也分层明显 |
| 单靶点药 | 97 个 | 局部图拓扑几乎固定；T1-local 的“真邻居 vs 根 vs 伪邻居”差 +0.0001 可解释 |
| DTI 方向 | 418 INHIBITOR、3 AGONIST、1 DEGRADER、1 ANTAGONIST、195 空 | 当前全部当无向根，浪费 action type |
| 随机对照 | random PPI 复现 T1 legacy +0.0169；T1-local 真邻居 ≈ 根 ≈ 伪邻居 | 图拓扑不是 T1 增益来源；T2 不应再堆静态图 |

> 相关性复算口径：`data/interim/teacher/ppi_features/340d2ab41f735ae8/features.npz`（`neighbor_mode=ppi`、213 个 coverage=True 的药 × 716 个细胞系），对 `rwr_{GE,MU,CNV}_mean` 与 `root_{GE,MU,CNV}_mean` 逐元素求 Pearson；四个 ppi 缓存给出相同结果。

### 3.3 四个失效机制

1. **信息冗余**：root summary / RWR 与 P1 target branch 读取同一组靶点基因；PPI 没有带来“P1 看不到的基因”。
2. **根节点主导**：RWR 的根权重约 0.50，邻居权重 ~0.002；传播几乎没有离开根。当前 `max_neighbors_per_target=8`、`max_nodes_per_drug=64` 又限制了多跳/多邻居。
3. **固定特征不可学习**：summary/RWR/pathway 都是一次性算好的线性统计；模型只能学一个 `context_mlp`，无法根据药物/细胞条件重新选择基因或重新加权。
4. **覆盖与信息内容不足**：73/286 无 DTI；DTI 是二值、无方向、无 affinity；pathway profile 是 membership × expression 的线性乘积，不能表达“通路内 vs 通路外”的对比（PASO）或 condition-specific rewiring（CSG²A）。

## 4. 改进方案

### 4.1 阶段 0：先做诊断与止损（约 1 周）

在改模型前，先把“先验到底有没有独立信息”测清楚：

0. **先修融合 gate**：当前学到的 α≈0.137 明显低估第二塔；同折 `t2_base` fixed 0.5 为 0.6175、`t2_all` 为 0.6196，均高于学习 gate 的 0.6121（T2 alone 0.6144）。先把 `fusion` 改成 fixed 0.5 或 per-sample gate，作为所有先验实验的共同基线；否则先验增益可能被融合 gate 掩盖。
1. **Target-only baseline**：P1 + 直接靶点 GE/CNV/MU + Morgan，不加任何 PPI。若 full PPI 打不过它，PPI 没有独立信息。
2. **Root-only / neighbor-only / full**：在 T2 的 context 里分别只给 root summary、只给 neighbor summary、给全部；确认当前增益来自哪一块。
3. **RWR 冗余审计**：重复本报告的相关系数计算；把 `rwr` 换成 `root summary` 的线性组合，看性能是否不变。
4. **Coverage strata**：OT / GDSC-only / no-DTI；single-target / multi-target；报告每层 ΔSCC 与配对 bootstrap CI。
5. **Action type 审计**：统计有方向 DTI 的药物/边；确认能否构建 signed propagation。

**止损**：若 target-only ≥ full PPI 的 95% CI 重叠，停止 L0 的“加特征”路线，直接进入 M1/M2/M3 的“换信息”路线。

### 4.2 阶段 1：三个最可能有效的改动（2–3 周）

#### M1：NetGP 式“间接靶点”传播（最高优先级）

**目标**：让 PPI 提供 P1 看不到的基因，而不是重复靶点表达。

**做法**：

1. 对每个药，取直接靶点作为 seed；按 `action_type` 赋符号（INHIBITOR/DEGRADER/ANTAGONIST = −1，AGONIST = +1，未知 = +1 或单独通道）。
2. 在 STRING v12.5 上做 degree-normalized propagation（当前 RWR 用列归一化、孤立节点自环；建议改用对称归一化 \(D^{-1/2}AD^{-1/2}\)，restart α 0.3–0.5，并显式处理孤立节点）。
3. 取 top 200 基因做通路富集（用项目已有的 1000 条通路权重）；把富集通路里的基因并回 seed，再传播；迭代 2–3 次到 top 200 稳定。
4. **排除直接靶点**，只保留“间接靶点”；按传播分数选 top-k（k=50/100/200 做敏感性）。
5. 对每个 drug–cell pair，读取这些间接靶点的 GE/CNV/MU（最好再加 pathway score），用一个小型 attention pooling / MLP 编码成 `netgp_context`。
6. 把 `netgp_context` 加到 T2 第二塔的 `z_pair`，并加一个 reliability gate：
   \[
   g_{d,c}=\sigma(\mathrm{MLP}([\text{coverage}, \text{tier}, \text{frac observed}, \text{propagation entropy}, \text{top-k score mass}]))
   \]
7. 保留当前 summary 作为对照，但**不要把 RWR 和 NetGP 同时塞进去**；先单独比较。

**为什么**：NetGP 是 strict unseen-drug 下最强的正面证据；NetGP/DGDRP 的路线把“直接靶点”和传播得到的“间接靶点”分开使用，而 T2 的 RWR 与 root 相关 0.96–0.99，等于没分开。

**对照**：
- root-only；
- 随机基因集（匹配基因数、全局 degree、表达可得性）；
- 保度重连 PPI；
- 靶点置换 DTI；
- pathway-shuffled enrichment；
- 真实 NetGP vs 随机传播。

**验收**：OT 子集逐药 SCC ≥ T2 base +0.005；且 ≥ root-only +0.003；且真实 PPI 比保度重连高 ≥ 80% 的增益；3 折 × 2 seeds 配对 CI 下限 > 0。

**实现位置**：新增 `src/kite_drp/train/netgp_features.py`；`ppi_features.py` 保留旧块用于 ablation；`t2.py` 加 `netgp_proj`；`configs/teacher/t2.yaml` 加 `ppi.netgp.*`。

#### M2：DTI 补全 + soft target profile

**目标**：覆盖 73 个无 DTI 药，并把“二值靶点”升级为“概率/多靶点 profile”。

**做法**：

1. 用 Morgan fingerprint（+ 可选药物图嵌入）训练 multi-label DTI predictor：输入 drug，输出 301 个 target gene 的概率；正样本 640 条边，负样本按 target 频率/药物频率做 stratified sampling。
2. 用 **drug-level CV**（留出药物）评估 DTI predictor 的 AUROC/AUPR；不要用同一药物的边同时训练和测试。
3. 对 213 个有 DTI 的药：known edges + top predicted edges（去重、截断 top-k）。
4. 对 73 个无 DTI 的药：只用 predicted profile；用 `coverage`/`confidence` gate 控制影响。
5. 构造 target profile 特征：
   - profile @ target gene expression（期望靶点活性）；
   - profile @ pathway weights（期望通路覆盖）；
   - profile 的 entropy / max / effective size（多靶点程度）；
   - 可选：profile 与 Morgan 的拼接，作为第二塔的 drug 侧输入。
6. 对“真正 cold drug”评测，做 **leave-one-drug-out DTI 补全**：训练 DTI predictor 时完全去掉该药的 DTI，再用预测 profile 做药敏推理。

**为什么**：DTLCDR 证明 predicted target profile 能提升 unseen-drug；T2 当前对 73 个药直接零填充，浪费了 1/4 的药物；KGDRP 的 DTI 辅助任务 ablation 也说明 target 信息最关键。

**对照**：
- zero-fill（当前）；
- known-only（仅 213 药，73 药回退）；
- predicted-only；
- known+predicted；
- target-permuted profile；
- random profile（同稀疏度）。

**验收**：no-DTI 子集 ≥ zero-fill +0.005；covered 子集不下降；cold-drug 的 DTI predictor 在 drug-level CV 上 AUPR 明显高于随机（至少 2× prevalence）。

**实现位置**：新增 `src/kite_drp/train/dti_completion.py`；`t2.py` 加 `target_profile_proj`；缓存 key 覆盖 DTI predictor 版本/训练药物集合。

#### M3：DTI 辅助预测头（KGDRP-lite）

**目标**：让第二塔在训练时被迫编码 target 生物学，而不是只记 drug ID。

**做法**：

1. 在 T2 第二塔的 drug embedding 上加一个 multi-label DTI head：`z_drug → 301 targets`，BCE；只有训练药有 DTI 标签，无 DTI 药 mask。
2. 可选加一个 pair-level DTI head：`z_drug` 与 gene embedding 的点积/MLP，正边来自 DTI，负边随机采样；这更接近 KGDRP 的 DTI predictor。
3. 可选加 pathway/GO head：从 cell embedding 预测 pathway activity 或 GO membership；权重小（0.05–0.1）。
4. 总损失：`L = L_response + λ_dti * L_dti + λ_path * L_path`；λ 从 0.05/0.1/0.2 扫。
5. 关键：**测试药的 DTI 不参与辅助任务训练**；只用于推理时的 target 输入（如果可用）。报告“DTI 可用/不可用”两种设置。

**为什么**：KGDRP 的 `noDTI` ablation 是三个辅助任务里下降最大的（cold-drug SCC 0.556→0.411）；辅助任务不需要新数据，成本低，且与 T2 的第二塔天然兼容。

**对照**：
- 无辅助头；
- DTI head + 随机标签（负对照）；
- DTI head + target-permuted；
- 只加 pathway head；
- 辅助权重 0（等价于 baseline）。

**验收**：cold-drug 逐药 SCC ≥ T2 base +0.003；且 DTI head 的 target 预测 AUPR 明显高于随机；若只提升 warm 不提升 cold-drug，停止。

**实现位置**：`t2.py` 加 `dti_aux_head`；`train/teacher_train.py` 支持 auxiliary loss；`configs/teacher/t2.yaml` 加 `aux.dti_weight`。

### 4.3 阶段 2：表征层改进（如果阶段 1 有正信号）

#### M4：PPI GraphMAE gene token / pathway token

**做法**：

1. 在 STRING 上构建 16,135 基因的图；节点特征可用基因在多细胞系中的表达/多组学，或 learnable embedding。
2. 用 GraphMAE（masked feature reconstruction + scaled cosine error）预训练 gene encoder。
3. 用预训练 embedding：
   - 加线性投影后初始化 P1 的 target gene embedding table（301 基因）；
   - 或聚合 member gene embedding、再投影到 d_model，初始化 1000 个 pathway token；
   - 或作为 M1 间接靶点编码器的 gene 侧输入。
4. 对照：random init、feature-only GraphMAE（去掉边）、degree-preserving shuffled PPI、不同 PPI 阈值（700/800/900）。

**为什么**：XPert 用 CellML 的 PPI GraphMAE 初始化 gene token；PINNACLE 用 PPI 自监督学习 context-specific protein representation。它把 PPI 学进表征，不增加主路径图分支，风险低于再建 GNN。

**验收**：LDO 逐药 SCC ≥ baseline +0.003；且真实 PPI 预训练 > shuffled PPI；若只有 warm 提升，停止。

#### M5：PPI/DTI 正则（低成本，但可能冗余）

**做法**：

- PPI Laplacian：\(\lambda_P \sum_{(i,j)\in E_{PPI}} w_{ij}\|h_i-h_j\|^2\)，作用在 gene embedding（靶点/间接靶点）上。
- DTI alignment：drug embedding \(z_d\) 与 target gene embedding 的 aggregate 做 contrastive/alignment；负样本用随机 target set。
- Pathway coherence：用 gene–pathway membership，让同一通路内的 gene embedding 更接近。

**为什么**：不改架构，只加损失；如果先验真实，应该能改善 cold-drug 表征。

**风险**：P1 target branch 已经很强，正则可能没有增量；需要随机 PPI/DTI 对照。

#### M6：Cell-specific PPI / contextualized protein embedding

**做法**：

- 用细胞系表达给 PPI 边加权：\(w_{ij}^{(c)} = w_{ij}\cdot f(e_{ci}, e_{cj})\)（如几何平均、共表达 z-score、或学习一个 edge gate）。
- 或按 PINNACLE 思路，构建 cell line-specific PPI，做 self-supervised link prediction，得到每个 cell line 的 protein embedding。
- 然后跑 M1 的传播或一个小 GNN。

**为什么**：静态 STRING 是 context-agnostic 的；同一 edge 在不同细胞系可能不表达/不功能。这是上一份调研指出的核心局限。

**风险**：成本高、容易过拟合；T1-local 的负结果说明“静态图 + 局部拓扑”不够，cell-specific 才可能有独立信息。建议在 M1–M3 有正信号后再做。

### 4.4 阶段 3：长线与差异化

#### M7：CSG²A/XPert 式 PPI-biased attention + LINCS 预训练

- 用 gene token transformer，PPI 邻接作为 attention bias；在 LINCS L1000 上预训练扰动响应，再迁移到 GDSC。
- 这是 CSG²A 的路线，cold-drug 证据强；但需要下载/处理 LINCS L1000（Level 3/5 签名数十 GB 量级，原始数据更大），计算成本高。
- 建议作为“如果 M1–M4 仍不够”的下一阶段，不作为当前主线。

#### M8：PPI/DTI 作为特权信息蒸馏（本项目最值得做）

**核心思想**：部署端的学生只输入 panel mutation + expression，不能用 PPI/DTI；但教师可以用。让教师把“通路级/靶点级知识”蒸给学生。

**设计**：

1. 教师变体：
   - T2-base（无 PPI）；
   - T2+NetGP；
   - T2+DTI-aux；
   - T2+NetGP+DTI-aux。
2. 学生：在教师变体之间保持相同架构、相同输入、相同初始化/种子；分别蒸馏每个教师的 `y_soft`（以及可选的 pathway/perturbation embedding）。
3. 评价：学生 LDO/LCO 的逐药 SCC、校准、分类；比较“教师有 PPI” vs “教师无 PPI”的学生增益。
4. 关键对照：教师软标签打乱（保留 drug 内分布）、教师集成、只用真标签。

**为什么**：即使教师 PPI 增益只有 +0.001，蒸馏也可能把“去噪/通路平滑”传给学生；而且这是本项目“端侧”叙事下最合理的 PPI/DTI 用法。文献里这类“privileged information distillation for DRP”很少，差异化空间大。

#### M9：把 PPI/DTI 用于靶点排序/机制解释

- 如果 IC50 端点上 PPI 始终没有稳定增益，可以把 PPI/DTI 用在 secondary endpoint：
  - 药物靶点排序（KGDRP target prioritization +26%；PDGrapher target ranking）；
  - MoA/pathway 解释；
  - 药物重定位。
- 这不改善主指标，但能提升论文的生物学价值和可解释性。

**优先级与成本（建议）**：

| 方案 | 新数据 | 代码改动 | 预期收益 | 优先级 |
|---|---|---|---|---|
| M0 融合 gate | 无 | 配置/融合层 | +0.005~0.007（fold0） | P0 |
| M1 NetGP 间接靶点 | 无 | 新特征 + 小头 | OT 子集 +0.003~0.008 | P0 |
| M2 DTI 补全 | 无 | DTI predictor + 特征 | no-DTI 子集 +0.005 | P1 |
| M3 DTI 辅助头 | 无 | 辅助 loss/头 | cold-drug +0.003 | P1 |
| M4 GraphMAE token | 无 | 离线预训练 + 投影 | +0.003 | P2 |
| M5 PPI/DTI 正则 | 无 | loss | 0~+0.003 | P2 |
| M6 cell-specific PPI | 无 | 逐细胞图/传播 | 不确定 | P2/P3 |
| M7 PPI-attention + LINCS | LINCS L1000 | 大改 + 预训练 | 可能较大，但成本高 | P3 |
| M8 特权信息蒸馏 | 无 | 蒸馏管线 | 学生增益 | P1（并行） |
| M9 靶点排序/解释 | 无 | 新端点 | 不改善主指标 | P3 |

| E13 | T2 + random PPI（保度重连） | 归因 | E5/E6 | 若复现 ≥80%，停止 |
| E14 | T2 + target-permuted DTI | 归因 | E5/E7 | 若复现，停止 |
| E15 | 学生蒸馏（教师 E1 vs E5/E8） | M8 | 同学生/同种子 | 学生增益 > 0，且优于无 PPI 教师 |

**执行顺序**：E0–E4（阶段 0 诊断）→ E5–E8（阶段 1）→ E10–E11（阶段 2）→ E12（阶段 2，可选）→ E15（并行准备）。

**规模**：先用 LDO fold0–2、seed0–1、12 epochs 快筛；入围后 5 折 × 3 seeds、正式早停/选模；scaffold-cold 与 double-cold 作为外推确认。

## 6. 评估与止损

### 6.1 主指标

- 主指标：LDO 的逐药 Spearman（per-drug SCC），药物等权平均；OT 子集为主，全量/无 DTI/GDSC-only 分层报告。
- 次指标：per-drug Pearson、RMSE、R²、分类 AUROC/AUPRC、校准。
- 统计：同药、同 seed 配对差 → 对 seed 等权 → 按药物实体配对 bootstrap 2,000 次；报告 95% CI。
- 选模：`val_per_drug_scc` 早停；测试集只在锁定比较矩阵后评估。

### 6.2 必做的对照

1. **均值基线**：细胞系均值、drug-mean、DrEval naive mean effects。
2. **Target-only**：直接靶点 GE/CNV/MU + Morgan，不加 PPI。
3. **Root-only / neighbor-only / full**。
4. **保度重连 PPI**：至少 3 个独立重连实例；报告根邻边替换率、连通分量。
5. **Target-permuted DTI**：保留靶点数/度分布，打乱药物–靶点对应。
6. **Pseudo-neighbor**：匹配节点数、全局 degree、组学可得性。
7. **Random gene set**：匹配基因数、表达分布、通路覆盖。
8. **Pathway-shuffled**：打乱基因–通路 membership，保留通路大小。
9. **Seed/初始化**：≥2 seeds；正式 ≥3 seeds。
10. **Leakage**：DTI predictor 只在训练药上训练；通路/基因选择在 fold 内；标准化在 fold 内；test drug DTI 不参与训练。

### 6.3 分层

- DTI 覆盖：OT / GDSC-only / no-DTI。
- 靶点数：single-target / multi-target。
- 药物类别：kinase inhibitor / cytotoxic / other（如果元数据可用）。
- 化学距离：test drug 与训练药的最大 Morgan–Tanimoto；报告“远/近”两层的 Δ。
- Target novelty：test drug 的靶点是否在训练药中出现过；区分“新药但老靶点”与“新药新靶点”。

### 6.4 止损/晋级规则

- **晋级**：OT 子集逐药 SCC ≥ T2 base +0.005，配对 95% CI 下限 > 0；且 ≥ target-only +0.003；且真实 PPI/DTI 比随机对照高 ≥80% 增益；3 折 × 2 seeds 方向一致。
- **止损**：
  - target-only ≥ full PPI 的 95% CI 重叠 → 停止 L0；
  - random PPI/DTI 复现 ≥80% 增益 → 停止图拓扑归因；
  - 只在 warm/cold-cell 有效、cold-drug 无效 → 不宣称新药泛化；
  - no-DTI 子集显著变差 → 不加 DTI 补全，或只对有 DTI 的药物启用；
  - 辅助任务只提升训练集/早停轮次 → 视为正则而非知识。
- **不要做**：在 test 集上调 λ/τ；用 test drug 的 DTI 训练 DTI predictor；把 pathway token 压成唯一输入；用随机图对照缺失的“SOTA”结论。

## 7. 论文叙事建议

1. **不要把负结果写成失败。** 可以写成“PPI/DTI 先验在 LDO 下的可迁移性边界”：
   - 贡献 1：严格的 random-graph / target-permuted / pseudo-neighbor / coverage-stratified 对照；
   - 贡献 2：证明 T1/T2 的增益来自第二塔/融合，而非 PPI/DTI 拓扑；
   - 贡献 3：从“先验当特征”升级到“先验当传播/辅助任务/特权信息”的系统比较；
   - 贡献 4：给出“什么时候 PPI/DTI 值得用”的决策规则（target-only baseline + cold-start protocol）。
2. **最有辨识度的路线**：PPI/DTI 作为 teacher 的特权信息，蒸馏给 edge student。文献里 strict cold-drug + privileged distillation + 端侧部署的组合很少；即使教师增益小，学生增益也可能是正的。
3. **不要承诺“机制解释”是因果。** 遮挡/attention/IG 只能说明“模型依赖哪些输入”；生物学机制需要独立验证。
4. **报告“覆盖组”和“全量”两个数字。** 213/286 覆盖下，全量 +0.005 需要覆盖组 +0.0067；如果只在 OT 子集有效，就明确限定。
