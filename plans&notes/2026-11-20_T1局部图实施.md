# T1 局部图实施记录（2026-11-20）

- 分支：`feat/t1-local-graph`（基于 `data/dti-opentargets-26.09`）
- 数据：DTI 迁移到 GDSC `TARGET` + Open Targets MoA 26.09；286 个化合物中
  213 个有任意 DTI，640 条边，301 个靶点基因；73 个药物无 DTI。
- 目标：用每药一跳局部图替换旧 T1 的全局异构图；先做快速验证，不直接进入
  5 折 × 3 seeds 正式比较。

## 1. 本次改动

- `src/kite_drp/train/local_graph.py`：每药局部图构建、缓存、审计、
  保度重连、匹配伪邻居。
- `src/kite_drp/train/data.py`：按 `(drug, cell)` 展开局部节点/边，
  细胞 GE/MU/CNV 在消息传递前写入节点。
- `src/kite_drp/models/teacher/t1_local.py`：冻结 P1 + 单层局部图残差；
  另有容量匹配的 `T1MlpHeadTeacher`。
- `configs/teacher/t1_local.yaml`、`t1_mlp.yaml`。
- `scripts/run_local_graph_quick.py`：快速筛选变体。
- `tests/train/test_local_graph.py`、`tests/models/test_t1_local_forward.py`：
  构图确定性、裁剪、保度重连、伪邻居、恒等初始化、精确回退、P1 冻结、
  批量一致性。

## 2. 快速验证协议

- P1：LDO `p2_ldo_s0` fold 0–1，seed 0，12 epochs，`val_per_drug_scc` 早停。
- T1 legacy：LDO fold 0，seed 0，用同折新 P1 checkpoint 初始化。
- T1-local 阶段 1：fold 0，seed 0，12 epochs；`root` / `neighbors` / `pseudo`
  都用集合编码（`propagation=set`），不传播。
- 阶段 2（待阶段 1 结果）：`no_prop`、`fixed_true`、`fixed_rewire`、
  `train_true`、`train_rewire`。
- 主指标：逐药 SCC 的宏平均；配对按 `(cell_line_uid, compound_uid)`。

## 3. 结果

| 变体 | 协议 | per-drug SCC | Δ vs P1 fold0 |
|---|---|---:|---:|
| P1 | LDO fold 0–1，seed 0 | **0.6245** | — |
| P1 fold0 | 同上 | 0.6228 | — |
| T1 legacy | LDO fold 0，seed 0 | **0.6397** | **+0.0169** |
| P1 + MLP 头 | LDO fold 0，seed 0 | **0.6233** | +0.0004 |
| 根集合 | 同上 | **0.6231** | +0.0003 |
| 真邻居集合 | 同上 | **0.6232** | +0.0004 |
| 匹配伪邻居 | 同上 | **0.6232** | +0.0003 |

阶段 1 结论：`neighbors − root = +0.0001`，`neighbors − pseudo = +0.0001`；
真邻居没有优于仅根或匹配伪邻居。按预注册门槛，**阶段 1 未通过，不进入
阶段 2**。作为事后诊断（不用于晋级），可训练传播 `train_true` 为 0.6233
（+0.0005），与集合编码相同；也就是说，当前残差头既没有从邻居选点、也没有
从消息传递中获得增量。MLP 头（+0.0004）也说明 55k 级容量不能解释 T1 legacy
的 +0.0169，但 T1 legacy 的 1.5M 图分支/深监督尚未做等容量对照，旧随机图
负对照仍是“图拓扑不成立”的主要证据。

T1 legacy 的增益集中在 OT 子集：OT +0.0372（22 个药）、GDSC-only +0.0043
（20 个药）、无 DTI +0.0037（15 个药）。因此局部图如果只在 GDSC-only 上
有增益，不能说明 PPI 上下文有效；必须看 OT / 有邻居子集。

## 4. 解释与限制

- 新 DTI 比旧版稀疏：301 个靶点基因、97 个单靶点药；局部图节点中位数约 9，
  多靶点药最多 64。单靶点药的根-邻居边固定，重连主要检验邻居间拓扑。
- 快速验证只跑 fold0、单 seed；`val_per_drug_scc` 同时用于早停和报告，
  数字偏乐观，不能作为正式结论。
- `p2_ldo_s0` 仍有 Bleomycin 盐型/别名跨折问题；正式主张要用实体分组 LDO。
- 旧 T1/P1 数字对应旧 DTI，不能与新数字直接比较。

## 5. 下一步

1. **先做读出头诊断**：`condition_on=none` / `cell`，检查 55k 残差头是否
   主要在使用 P1 `z_pair`；当前 `local_delta` 的组内标准差约 0.07，但逐药
   SCC 没有提升，像是学到了不影响排序的药物/细胞修正。
2. **强制图分支学习**：给局部图加独立的 graph-only 头与深监督（类似旧 T1
   的 `y_graph`），或对残差做逐药中心化/排序正则，避免 Huber 只学药物偏移。
3. **节点编码增强**：在共享投影之外加入 P1 基因表 embedding、attention
   pooling、边权/首层 top-k；先做单折消融，不直接上 2 跳。
4. **T1 legacy 容量对照**：用 1.5M 级 MLP 头 + 新 DTI 的 random PPI/DTI
   重跑，确认 +0.0169 是否仍是容量/集成效应；旧随机图结论不能直接套到新 DTI。
5. **正式协议只在设计通过后启动**：实体分组 LDO 5 折 × 3 seeds，逐药配对
   bootstrap；归因连边要求真图同时优于 `no_prop` 和 `rewire`。
6. 补 `condition_on=cell/none` 与残差收缩，检查盲药负迁移。
