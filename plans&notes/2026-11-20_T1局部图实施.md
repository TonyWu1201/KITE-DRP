# T1 局部图实施记录（2026-11-20）

- 分支：`feat/t1-local-graph`（基于 `data/dti-opentargets-26.09`）
- 数据：DTI 迁移到 GDSC `TARGET` + Open Targets MoA 26.09；286 个化合物中
  213 个有任意 DTI，640 条边，301 个靶点基因；73 个药物无 DTI。
- 目标：用每药一跳局部图替换旧 T1 的全局异构图；先做快速验证，不直接进入
  5 折 × 3 seeds 正式比较。

## 1. 本次改动

- `src/kite_drp/train/local_graph.py`：每药局部图构建、缓存、审计、
  保度重连、匹配伪邻居。
- `src/kite_drp/train/data.py`：按 `(drug, cell)` 展开局部节点/边，
  细胞 GE/MU/CNV 在消息传递前写入节点。
- `src/kite_drp/models/teacher/t1_local.py`：冻结 P1 + 单层局部图残差；
  另有容量匹配的 `T1MlpHeadTeacher`。
- `configs/teacher/t1_local.yaml`、`t1_mlp.yaml`。
- `scripts/run_local_graph_quick.py`：快速筛选变体。
- `tests/train/test_local_graph.py`、`tests/models/test_t1_local_forward.py`：
  构图确定性、裁剪、保度重连、伪邻居、恒等初始化、精确回退、P1 冻结、
  批量一致性。

## 2. 快速验证协议

- P1：LDO `p2_ldo_s0` fold 0–1，seed 0，12 epochs，`val_per_drug_scc` 早停。
- T1 legacy：LDO fold 0，seed 0，用同折新 P1 checkpoint 初始化。
- T1-local 阶段 1：fold 0，seed 0，12 epochs；`root` / `neighbors` / `pseudo`
  都用集合编码（`propagation=set`），不传播。
- 阶段 2（待阶段 1 结果）：`no_prop`、`fixed_true`、`fixed_rewire`、
  `train_true`、`train_rewire`。
- 主指标：逐药 SCC 的宏平均；配对按 `(cell_line_uid, compound_uid)`。

## 3. 结果

| 变体 | 协议 | per-drug SCC | Δ vs P1 fold0 |
|---|---|---:|---:|
| P1 | LDO fold 0–1，seed 0 | **0.6245** | — |
| P1 fold0 | 同上 | 0.6228 | — |
| T1 legacy | LDO fold 0，seed 0 | **0.6397** | **+0.0169** |
| P1 + MLP 头 | LDO fold 0，seed 0 | **0.6233** | +0.0004 |
| 根集合 | 同上 | **0.6231** | +0.0003 |
| 真邻居集合 | 同上 | **0.6232** | +0.0004 |
| 匹配伪邻居 | 同上 | **0.6232** | +0.0003 |

阶段 1 结论：`neighbors − root = +0.0001`，`neighbors − pseudo = +0.0001`；
真邻居没有优于仅根或匹配伪邻居。按预注册门槛，**阶段 1 未通过，不进入
阶段 2**。作为事后诊断（不用于晋级），可训练传播 `train_true` 为 0.6233
（+0.0005），与集合编码相同；也就是说，当前残差头既没有从邻居选点、也没有
从消息传递中获得增量。MLP 头（+0.0004）也说明 55k 级容量不能解释 T1 legacy
的 +0.0169，但 T1 legacy 的 1.5M 图分支/深监督尚未做等容量对照，旧随机图
负对照仍是“图拓扑不成立”的主要证据。

T1 legacy 的增益集中在 OT 子集：OT +0.0372（22 个药）、GDSC-only +0.0043
（20 个药）、无 DTI +0.0037（15 个药）。因此局部图如果只在 GDSC-only 上
有增益，不能说明 PPI 上下文有效；必须看 OT / 有邻居子集。

## 4. 解释与限制

- 新 DTI 比旧版稀疏：301 个靶点基因、97 个单靶点药；局部图节点中位数约 9，
  多靶点药最多 64。单靶点药的根-邻居边固定，重连主要检验邻居间拓扑。
- 快速验证只跑 fold0、单 seed；`val_per_drug_scc` 同时用于早停和报告，
  数字偏乐观，不能作为正式结论。
- `p2_ldo_s0` 仍有 Bleomycin 盐型/别名跨折问题；正式主张要用实体分组 LDO。
- 旧 T1/P1 数字对应旧 DTI，不能与新数字直接比较。

## 5. 下一步

1. **先做读出头诊断**：`condition_on=none` / `cell`，检查 55k 残差头是否
   主要在使用 P1 `z_pair`；当前 `local_delta` 的组内标准差约 0.07，但逐药
   SCC 没有提升，像是学到了不影响排序的药物/细胞修正。
2. **强制图分支学习**：给局部图加独立的 graph-only 头与深监督（类似旧 T1
   的 `y_graph`），或对残差做逐药中心化/排序正则，避免 Huber 只学药物偏移。
3. **节点编码增强**：在共享投影之外加入 P1 基因表 embedding、attention
   pooling、边权/首层 top-k；先做单折消融，不直接上 2 跳。
4. **T1 legacy 容量对照**：用 1.5M 级 MLP 头 + 新 DTI 的 random PPI/DTI
   重跑，确认 +0.0169 是否仍是容量/集成效应；旧随机图结论不能直接套到新 DTI。
5. **正式协议只在设计通过后启动**：实体分组 LDO 5 折 × 3 seeds，逐药配对
   bootstrap；归因连边要求真图同时优于 `no_prop` 和 `rewire`。
6. 补 `condition_on=cell/none` 与残差收缩，检查盲药负迁移。

## 6. 第二轮改进（同日）

### 6.1 改动

- 局部图新增 STRING 边权 `edge_weight`、P1 靶点行掩码 `gene_is_target`；缓存键
  增加靶点掩码哈希，代码版本升到 `local_graph_v3`。
- `T1LocalTeacher` 新增：
  - `graph_head`：独立 graph-only 头 `y_graph`，训练时用
    `teacher.train.graph_weight` 深监督；
  - `graph_rank_weight`：对 `y_graph` 做逐药 pairwise rank 深监督；
  - `center_weight`：惩罚逐药残差均值，限制局部图只改药内排序；
  - `attention_pool`：根/非根分别做 masked attention pooling；
  - `use_gene_embedding`：节点读取冻结 P1 靶点基因表（非靶点行置零）；
  - `edge_weighted`：按 STRING 边权做邻居均值。
- 新增 `mlp_match`（56,245 可训练参数，对齐 graph-only 的 55,042）与
  `mlp15`（1,499,853 可训练参数）容量对照。
- 快速筛选新增 `no_pair`、`cell_cond`、`gonly`、`gonly_rank`、`gonly_alpha`、
  `gonly_prop`、`gonly_gene`、`center`、`t1_rand_ppi`、`t1_rand_dti`。

### 6.2 结果

协议同前：LDO fold0、seed0、12 epochs、`val_per_drug_scc` 早停。

| 变体 | per-drug SCC | Δ vs P1 fold0 | graph-only SCC | 说明 |
|---|---:|---:|---:|---|
| P1 fold0 | 0.6228 | — | — | 对照 |
| 无 P1 成对表征（`no_pair`） | 0.6231 | +0.0003 | — | 仅图池化 + 标记 |
| 仅 P1 细胞表征（`cell_cond`） | 0.6231 | +0.0003 | — | 去掉药物侧 `z_pair` |
| graph-only 深监督（`gonly`） | 0.6228 | −0.0000 | **0.6060** | `y_graph` 自身明显低于 P1 |
| graph-only + 逐药排序（`gonly_rank`） | 0.6228 | −0.0000 | **0.6020** | 排序深监督未救回 |
| 增强节点编码 + 传播（`gonly_gene`） | 0.6228 | −0.0000 | **0.6024** | 边权/attention/基因表仍无增益 |
| 逐药中心化（`center`） | 0.6232 | +0.0003 | — | 与普通残差头相同 |
| 容量匹配 MLP（56k） | 0.6232 | +0.0004 | — | 容量不解释增益 |

`gonly` 的融合系数 `tanh(graph_alpha)` 在 7 个 epoch 内只从 0.003 升到 0.033，
随后早停；`gonly_rank` 的系数转为负值。也就是说，graph-only 头自身学到的排序
比 P1 差，主损失没有理由把融合权重推大。

`gonly` 的 graph-only 头在 OT 子集上更差（−0.0261），而 T1 legacy 的增益恰好
集中在 OT（+0.0372）。这说明新 DTI 下“每药一跳局部图 + 当前细胞组学”没有
复现 T1 legacy 的 OT 增益。

### 6.3 T1 legacy 对照

| 变体 | per-drug SCC | Δ vs P1 fold0 | 说明 |
|---|---:|---:|---|
| T1 legacy | 0.6397 | +0.0169 | 真实 PPI + DTI + cell-gene 图 |
| T1 + random PPI | **0.6398** | **+0.0169** | 保度重连 PPI；几乎完全复现 |
| T1 + random DTI | **0.6378** | **+0.0150** | 保度重连 DTI；复现约 89% |
| 1.5M MLP 头（冻结 P1） | 0.6237 | +0.0009 | 容量不解释 T1 增益 |
| T1 冻结 P1 | **0.6384** | **+0.0156** | 仍保留几乎全部增益 |
| T1 去 cell-gene 边 | **0.6388** | **+0.0160** | 仍保留几乎全部增益 |

随机 PPI/DTI 都保留了真实 T1 的增益和 OT 分层（random PPI 的 OT 子集
+0.0372），说明 **PPI/DTI 拓扑不是 T1 legacy 增益的来源**。1.5M MLP 头只有
+0.0009，说明 **额外预测头容量也不是主因**；冻结 P1 仍有 +0.0156、去掉
cell-gene 边仍有 +0.0160，说明 **P1 联合微调和 cell-gene 边也不是主因**。

排除后，T1 的剩余增益只能来自：图分支对药物（Morgan + targets）和细胞
（GE/MU/CNV）的**独立第二套编码 + 与 P1 的门控融合**，即一个多视角集成/
第二塔，而不是任何图边。`t1_no_cg` 仍保留 OT +0.0368、GDSC-only +0.0032、
无 DTI +0.0027，与真实 T1 的分层几乎一致。

### 6.4 阶段结论

- 第二轮改进仍未通过阶段 1：`neighbors − root` 与 `neighbors − pseudo` 仍在
  +0.0001 量级；graph-only 头自身 0.602–0.606，低于 P1 0.623。增强节点编码
  + 传播（`gonly_gene`）仍是 0.6024，没有把局部图变成可用信号。
- 读出头诊断显示 `z_pair`、`z_cell`、`none` 三种条件都在 +0.0003 左右；当前
  55k 残差头没有把图特征转成可泛化的药内排序。
- 因此不进入阶段 2 传播对照，也不启动正式 5 折 × 3 seeds；局部图分支归档为
  负结果。
- T1 legacy 的 +0.0169 已归因为 **独立第二塔 + 融合**，不是 PPI/DTI 拓扑、
  cell-gene 边、P1 微调或单纯头容量。若追求这部分增益，下一步应做**无图的
  第二塔集成**（Morgan + targets + 细胞组学的独立编码，门控融合 P1），而不是
  继续加图边或做正式图教师评估。
