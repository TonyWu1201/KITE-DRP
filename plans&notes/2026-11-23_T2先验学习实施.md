# T2 生物先验学习：S0/S1 实施记录（2026-11-23）

- 分支：`feat/t2-bio-prior`（基于 `master@25d2e71`）
- 目标：把 T2 从“再加一个静态 PPI 特征”改成“先验分支可辨识、可归因、
  可单独评估”；主线判据从“LDO 涨点”改为“教师是否真正学到先验”。
- 证据等级：本轮只做实现与诊断接口，不产生新的性能结论。所有筛选仍是
  LDO fold0–2、seed0、12 epochs 的快速证据；正式结论必须走 5 折 test。

## 1. 为什么改读出，而不是先加特征

上一轮实测（`2026-11-23_PPI-DTI先验学习与T2改进调研.md` §3）已经说明：

1. RWR 与 root 集合统计相关 GE 0.963 / MU 0.991 / CNV 0.984；tower 的
   `target_branch` 和 `use_targets` 已经读取同一组靶点基因，root/RWR 是
   三重冗余；
2. 遮挡实验测的是最终 `y_hat = y_p1 + tanh(α)(y_t2 − y_p1)`，被 α≈0.137
   线性缩放；`zero_summary −0.0026` 在 `y_t2` 上约 −0.019，绝对量级被低估；
3. `z_pair += context` 不可辨识：head 可以绕过 context，且没有独立输出，
   无法回答“先验自己有多强”。

因此本轮先做 **S0 测量修复**，再做 **S1 NetGP 间接靶点**。

## 2. S0：可辨识读出与诊断

### 2.1 模型（`src/kite_drp/models/teacher/t2.py`）

新增三个互相独立的开关：

| 开关 | 取值 | 含义 |
|---|---|---|
| `t2.context_mode` | `add` / `head` / `both` | 先验是否加入 `z_pair`；`head` 只走独立输出 |
| `t2.fusion` | `global` / `mean` / `sample` / `none` | `none` = 最终输出只用 P1，塔/先验头靠深监督训练 |
| `train.ctx_weight` | float | 先验独立头 `y_ctx` 的 Huber 深监督权重 |

`head`/`both` 模式下新增：

```
y_ctx, logits_ctx = ctx_head(context)
y_t2_ctx = y_t2 + tanh(ctx_gate) * y_ctx        # ctx_gate 初始 0（可配）
y_hat    = y_p1 + blend * (y_t2_ctx - y_p1)
```

`aux` 现在包含 `y_p1`、`y_t2`（纯塔）、`y_ctx`（纯先验）、`y_t2_ctx`
（塔 + 门控先验）、`context_gate`、`ctx_gate`、`netgp_gate`。因此可以在
同一份 `val_predictions.parquet` 里分别评估三段，而不必重训。

### 2.2 可靠性 gate

`ppi_meta`（coverage / tier one-hot / 根数 / 邻居数）和
`netgp_reliability`（覆盖、tier、选中比例、权重熵、top1 质量、
max score、根数）拼起来过一个 2 层 MLP：

```
gate = sigmoid(context_scale + gate_mlp([meta, reliability]))
```

最后一层零初始化，所以初始等价于旧的全局 `context_scale`；训练中可以
按药物/细胞调节“先验该信多少”。

### 2.3 诊断脚本

| 脚本 | 作用 |
|---|---|
| `scripts/calibrate_t2_blend.py` | val 上网格搜索 `y = y_p1 + w_t(y_t2−y_p1) + w_c y_ctx`，冻结 `(w_t*, w_c*)` 后只评估一次 test；输出 per-drug SCC / 配对 bootstrap |
| `scripts/probe_ppi_ceiling.py` | 用 Ridge + 药物分组 CV 预测 `y − y_p1`，报 OOF R² 与 `y_p1+r̂` 的逐药 SCC；列 shuffle / 药物置换作零分布 |
| `scripts/analyze_t2_interpretability.py` | 遮挡同时记录 `y_hat`、`y_t2`、`y_ctx`，输出 `delta_{block}_t2` / `_ctx` |

`probe_ppi_ceiling.py` 是 go/no-go 的核心：如果每个 block 的 OOF R² 都
不高于 shuffle 零分布，说明现有特征空间已经被 P1 用完，继续调读出没有意义。

## 3. S1：NetGP 间接靶点

### 3.1 特征（`src/kite_drp/train/netgp_features.py`）

- 根：复用 `build_local_graphs` 的 canonical DTI tier 规则（OT + GDSC）；
- 传播：STRING 上 personalized PageRank，`restart` 默认 0.5、`steps` 20；
  `normalization=symmetric`（可切 `row`）；
- **排除直接靶点**，取 top-k（默认 64）；
- 可选通路 ORA：对 top-N 基因做超几何检验，`-log10(p)` 作为 pathway profile；
  `pathway_reseed=true` 时把显著通路成员并回种子再传播（默认关闭）；
- 输出：`gene_ids (n_drugs,K)`、`gene_weight`、`pathway_profile`、
  `reliability (n_drugs,8)`、`meta (n_drugs,8)`、`coverage/tier`；
- 缓存键覆盖 DTI/PPI/通路哈希、基因空间、全部配置和代码版本；
- 归因对照内置：
  - `graph_control=configuration`：保度 stub matching 随机图；
  - `dti_control=permute_drugs`：tier 内打乱药物–靶点对应；
  - `gene_control=random_matched`：保留根，按度分位替换间接基因。

特征本身是药物级的；细胞侧的值在 `data.py` collate 里按 `(drug, cell)`
读取，因此同一套基因选择可以在所有 fold 复用，而组学值仍是 fold 内标准化。

### 3.2 模型接入

`T2DualTeacher` 新增一个 `TargetGeneEncoder` 风格的 NetGP token：

- 与 tower 的 target branch **共享基因嵌入表**；
- 输入是 `(B,K,2M)` 的组学值 + availability + 传播权重（作为第 7 个通道）；
- 一个 attention pool 得到 token，乘 `tanh(netgp_gate)` 后加到 context；
- `netgp_gate` 初始 0，避免早期随机扰动。

## 4. 实验臂

`scripts/run_t2_quick.py` 新增：

| 臂 | 目的 |
|---|---|
| `t2_decomp_p1` | 只训塔、`fusion=none` 的分解基线（monitor `val_t2_per_drug_scc`） |
| `t2_ctxhead` | 当前 summary/rwr/pathway + 独立先验头 |
| `t2_meta` | 只有药物级 meta（靶点数/tier）的混杂对照 |
| `t2_netgp` | NetGP 间接靶点 + 独立头（塔 + 门控先验，`ctx_gate_init=1`） |
| `t2_netgp_add` | NetGP 走旧的 `z_pair += context`，对照读出差异 |
| `t2_netgp_pathway` | NetGP + ORA 重播种 |
| `t2_netgp_rewire` / `_permute` / `_random` | 三种归因对照 |
| `t2_prior_only` / `_rewire` / `_permute` / `_random` | 只训 `y_ctx`，回答 Q1“先验是否可学” |

推荐顺序：

```bash
# S0：分解 + 残差探针
uv run python scripts/run_t2_quick.py \
  --variants t2_decomp_p1,t2_meta,t2_ctxhead \
  --folds 0,1,2 --seeds 0 --epochs 12 \
  --init-from experiments/p1_ldo_quick/runs/p1_s0 \
  --out experiments/t2_prior_s0

uv run python scripts/probe_ppi_ceiling.py \
  --run experiments/t2_prior_s0/runs/t2_ctxhead_s0 --fold 0 \
  --out experiments/analysis/ppi_probe_f0

# S1：净 NetGP + 对照
uv run python scripts/run_t2_quick.py \
  --variants t2_prior_only,t2_prior_only_rewire,t2_prior_only_permute,t2_prior_only_random \
  --folds 0,1,2 --seeds 0 --epochs 12 \
  --init-from experiments/p1_ldo_quick/runs/p1_s0 \
  --out experiments/t2_prior_q1
```

`t2_prior_only` 的 monitor 是 `val_ctx_per_drug_scc`，所以 early stopping
看的是先验头本身，不是被冻结的 P1。

## 5. 判据（与上一轮讨论一致）

- **Q1 先验可学**：`t2_prior_only` 的 test 逐药 SCC 高于三种对照；且
  reliability gate 在 OT / gdsc_only / none 上单调（OT > gdsc_only > none）。
- **Q2 先验有用**：`t2_netgp` 经 `calibrate_t2_blend.py` 校准后，5 折 test
  的配对 ΔSCC 优于 `t2_ctxhead`、`t2_netgp_rewire`、`t2_netgp_random`。
- **止损**：`probe_ppi_ceiling.py` 所有 block 的 OOF R² 不高于 shuffle；
  或 rewire/random 复现 ≥80% 增益；或 `t2_prior_only` 不优于随机先验。

## 6. 尚未实施（下一提交）

1. **S2 masked target aux**：训练时随机遮 20–30% DTI 边，用独立的
   `drug0_masked` 预测被遮边；需要 `dti_targets.py` 和额外的 drug encoder
   forward。注意当前 tower 的 `use_targets=true`，直接 `z_drug → targets`
   是恒等任务，必须先遮边。
2. **S3 no-target token**：73 个无 DTI 药同时无 GDSC target，且多为细胞毒/
   未识别化合物；计划加 learned missing token + 机制类别，而不是做
   `Morgan → target` 补全（后者是 Morgan 的确定性函数，不带来新信息）。
3. **5 折 test 正式确认**：`eval_test=true` + 预注册臂列表；当前脚本默认
   `train.eval_test=false`，只报 val。

## 7. 已知限制

- `t2_meta` 的输入是逐药常数，**不会改变逐药 SCC**（层内排序对药物级常数
  不敏感）；它只用于全局指标/ gate 诊断，不能当作“靶点数混杂”的强对照。
- `probe_ppi_ceiling.py` 在 val 上做药物分组 CV，只能回答“特征空间是否还有
  信息”，不能作为 test 结论；test 必须用 `calibrate_t2_blend.py`。
- NetGP 的 `pathway_reseed` 依赖 1000 条 GO/Reactome 通路，ORA 的 background
  取图内基因数（16,135）；换通路库会改变 profile，需要重新审计。
- 新模块仍在 `backbone`/`tower` 之后构造，保持跨变体的初始化配对；若未来
  把先验模块提前构造，会破坏 paired 比较。

## 8. 首轮结果（2026-11-23，LDO fold0–2 × seed0 × 12 epochs，val）

全部 13 个臂已完成；指标是折内逐药 SCC 的 3 折均值。`fusion=none` 的
`per_drug_scc` 按设计等于冻结 P1，因此看 `t2_per_drug_scc` / `ctx_per_drug_scc`。

| 臂 | final | t2（纯塔） | t2_ctx（塔+先验） | ctx（纯先验） |
|---|---:|---:|---:|---:|
| `t2_decomp_p1` | 0.6312 | **0.6368** | 0.6368 | — |
| `t2_meta` | 0.6355 | 0.6339 | 0.6339 | — |
| `t2_ctxhead` | 0.6312 | 0.6362 | 0.6218 | **0.3873** |
| `t2_prior_only` | 0.6312 | 0.6361 | 0.6361 | **0.3004** |
| `t2_prior_only_rewire` | 0.6312 | 0.6327 | 0.6327 | 0.2722 |
| `t2_prior_only_permute` | 0.6312 | 0.6352 | 0.6352 | 0.2829 |
| `t2_prior_only_random` | 0.6312 | 0.6190 | 0.6190 | 0.2371 |
| `t2_netgp` | 0.6312 | 0.6359 | 0.6207 | 0.2997 |
| `t2_netgp_add` | 0.6357 | 0.6351 | 0.6351 | — |
| `t2_netgp_rewire` | 0.6312 | 0.6356 | 0.6192 | 0.2708 |
| `t2_netgp_permute` | 0.6312 | 0.6350 | 0.6173 | 0.2597 |
| `t2_netgp_random` | 0.6312 | 0.6357 | 0.6179 | 0.2334 |
| `t2_netgp_pathway` | 0.6312 | 0.6357 | 0.6221 | 0.3050 |

### 8.1 最重要的对照：cell-mean 基线

用**训练药**估计每个细胞系的平均响应，再在 val 上预测（DrEval 的 naive
mean effects）：

| fold | cell-mean 逐药 SCC | P1 逐药 SCC |
|---|---:|---:|
| 0 | 0.6040 | 0.6065 |
| 1 | 0.6224 | 0.6202 |
| 2 | 0.6694 | 0.6670 |
| 均值 | **0.6319** | **0.6312** |

**P1 恰好落在 cell-mean 基线上。** 这说明当前逐药 SCC 主要由「细胞系固有
敏感度」驱动，而不是药物特异机制；P1/T2 的 0.63 不是“学会了药敏”，而是
“学会了细胞系平均敏感度”。塔的 +0.0056 和融合的 +0.007 是真实的增量，
但都是在这个基线之上的小量。

### 8.2 Q1：先验是否可学

prior-only 头在 3 折上：

| 先验 | ctx 逐药 SCC | 相对 real |
|---|---:|---:|
| real NetGP | 0.3004 | — |
| permute DTI（tier 内换药） | 0.2829 | −0.0175 |
| rewire（保度随机图） | 0.2722 | −0.0282 |
| random matched genes | 0.2371 | −0.0633 |

逐折看：real > random 3/3；real > permute 3/3（+0.012/+0.026/+0.015）；
real > rewire 2/3（fold2 −0.001）。因此：

- **药物特异的基因选择确实携带可学信息**（real vs random 稳定为正）；
- **拓扑的独立贡献较小且不稳定**（fold2 rewire 追平）；
- 但 prior-only 的绝对值 0.30 远低于 cell-mean 基线 0.63——它没有 cell-level
  基线特征，不能单独作为药敏预测器。这里的“可学”是相对对照，不是绝对性能。

### 8.3 Q2：先验对融合预测是否有用

用 `calibrate_t2_blend.py` 在 val 上选 `w_t, w_c`（`y = y_p1 + w_t(y_t2−y_p1) + w_c y_ctx`）：

| 先验 | 选中的 w_t / w_c（f0/f1/f2） | 融合 SCC（3 折均值） | 相对 P1 |
|---|---|---|---:|
| real | 0.65/0.00, 0.60/0.10, 0.60/0.05 | 0.6391 | +0.0079 |
| permute | 0.60/−0.05, 0.55/0.05, 0.60/0.00 | 0.6387 | +0.0075 |
| rewire | 0.40/−0.05, 0.60/0.00, 0.60/0.05 | 0.6375 | +0.0063 |
| random | 0.25/−0.05, 0.30/0.00, 0.40/0.00 | 0.6337 | +0.0025 |

- `w_t≈0.6`：主要增益来自 **P1 + 塔** 的融合，不是先验；
- `w_c≈0–0.1`，且跨折不稳定；先验相对塔的边际约 **+0.0004**；
- **real ≈ permute**（0.6391 vs 0.6387），说明融合增益里几乎没有“药物-靶点
  对应”的特异成分，更多是通用的 DTI 邻域表达信号。

OT 分层（60 个折-药观测，val 选权重）：

| 先验 | OT 融合 SCC | 相对 P1 |
|---|---:|---:|
| real | 0.6223 | +0.0139 |
| permute | 0.6215 | +0.0131 |
| rewire | 0.6187 | +0.0103 |
| random | 0.6128 | +0.0044 |

OT 上 real 比 permute 只高 **+0.0008**，远低于预注册的 +0.005 阈值。

### 8.4 读出与 gate

- `ctx_gate_init=1.0`（塔+先验固定 0.76 权重）在 3 折上都低于纯塔：
  `t2_netgp` 0.6207 vs `t2_decomp_p1` 0.6368；`t2_ctxhead` 0.6218。先验头
  比塔弱，单个全局 gate 无法按药/细胞降权。**先验必须走事后校准或 per-pair
  gate，不能用一个开着的全局标量。**
- `t2_prior_only`（`ctx_gate=0`）的塔与纯塔一致（0.6361），说明关闭 gate 后
  塔不受影响；先验只在 `y_ctx` 里，可单独评估/校准。

## 9. 决策（按预注册止损规则）

1. **停止“再加 PPI/DTI 先验特征”的 L0/L3 主线。** Q2 的融合增量约 +0.0005，
   OT 上 real vs permute +0.0008，均低于 +0.005；rewire/random 也没有被稳定
   拉开。
2. **先修评测，再谈模型。** 当前逐药 SCC 与 cell-mean 基线几乎相同；任何
   “+0.005”都必须同时报告 cell-mean 基线和相对它的增量。建议下一版主指标
   增加：
   - cell-mean（训练药估计）作为强制基线；
   - cell-mean-adjusted 或 within-cell across-drug 的 drug-specific 指标
     （需要 cross-fitting，避免用同一批标签残差化）；
   - 继续保留逐药 SCC 作为次要指标。
3. **主线转向**：按 `2026-11-23_PPI-DTI先验学习与T2改进调研.md` §6.4，
   Q2 为负后应转 **M8 特权信息蒸馏** 或 **M9 靶点排序/机制解释**；不建议
   继续做 M4/M5/M6。
4. **保留的正面结果**：NetGP 的间接靶点具有 face validity（EGFR/MAPK/
   Aurora/AR 邻域），且 real > random/permute 的 prior-only 差异稳定；这可以
   作为“先验可学但被现有细胞系基线覆盖”的负结果叙事，而不是性能卖点。
5. **下一步最小实验**（如果继续）：
   - 用 cross-fitted cell-mean 重算所有臂的 drug-specific 增量；
   - 只在这个增量上重跑 `t2_prior_only` real vs permute vs random（不必重训，
     用已有 `y_ctx_pred`）；
   - 若 drug-specific 增量仍 < +0.003，正式关闭先验主线。
