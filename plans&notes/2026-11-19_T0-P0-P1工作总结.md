## 1. 结论先行

1. **T0 v1 仍然是默认可复现基线**：`configs/teacher/t0.yaml` 未改动。
2. **P0 没有带来 SCC 提升**：排序损失不稳定，完整 P0（hybrid readout + rank 0.5 + 4×128）
   明显低于 v1；P0-lite（sum + no-rank + 8×64）与 v1 基本打平。
3. **P1 是目前最强的无图候选**：target-aware gene branch + 低秩 cls_proj，
   4 个快速验证观测 SCC 0.440 vs v1 0.415，R² 0.170 vs 0.156；
   但逐 seed/fold 波动大，t≈1.79（n=4），**只能作为方向性证据**。
4. **共享 pathway embedding 的假设不成立**：quick screen 中明显低于独立通路表，
   默认关闭；参数节省不值得。
5. **`cls_proj` 不能直接删**：完全去掉会明显掉点；低秩共享投影
   （1000→64→256）是更合理的折中。
6. **图结构尚未开始验证**：T1 还没实现。T0/P1 的角色是“无图对照/兜底教师”；
   正式检验图结构时应使用 **T1 vs 最强无图教师（P1 或 T0）**，并加随机图负对照。

## 2. 实现内容

### 2.1 P0（commit `ec3bd87`）

- 同药物 pairwise ranking loss（`src/kite_drp/train/losses.py`）；
- drug-balanced batch sampler（每个 epoch 覆盖全部训练 pair）；
- token type / top-k rank embedding / attention pooling / hybrid readout；
- GE/MU/CNV 缺失 mask、presence vector、cross-attention gate；
- 逐折独立 seed、可选 EMA、per-drug SCC、test 单次评估入口；
- 配置：`configs/teacher/t0_p0.yaml`、`configs/teacher/t0_p0_lite.yaml`。

### 2.2 P1（commit `8a4e017`）

- 逐基因细胞特征：`gene_ge` / `gene_mu` / `gene_cnv` + 有效性 mask（18,396 基因）；
- 每个 `(drug, cell)` pair 的靶点基因表，cap=64，值 + availability flag；
- `TargetGeneEncoder`：
  - 基因 ID 嵌入与药物靶点 `EmbeddingBag` 共享；
  - 1 层 target self-attention + attention pooling；
  - target token 参与 cross/self-attention，gate 初始 0；
- `cls_proj_mode`：`full` / `shared` / `lowrank` / `none`；
- `shared_pathway` / `shared_pathway_proj` 开关；
- 配置：`configs/teacher/t0_p1.yaml`（4,889,862 参数）。

## 3. 快速验证结果

协议：LCO `p1_lco_s0`，folds 0/2，seeds 0/1，5 epochs，patience 5，batch 512。

| 变体 | 参数 | R² | SCC | AUROC | per-drug SCC |
|---|---:|---:|---:|---:|---:|
| T0 v1 | 4,728,260 | 0.156 ± 0.049 | 0.415 ± 0.054 | 0.700 ± 0.024 | 0.411 ± 0.052 |
| **T0 P1** | 4,889,862 | **0.170 ± 0.054** | **0.440 ± 0.062** | **0.710 ± 0.031** | **0.436 ± 0.057** |
| P1 去掉 target branch | 4,092,677 | 0.114 ± 0.061 | 0.417 ± 0.051 | 0.702 ± 0.025 | 0.411 ± 0.046 |
| P0-lite | 4,780,741 | 0.166 ± 0.045 | 0.410 ± 0.049 | 0.698 ± 0.022 | 0.405 ± 0.047 |

P1 相对 v1：ΔSCC +0.025、ΔR² +0.014、ΔAUROC +0.009。

逐 (seed, fold) ΔSCC：

| seed | fold | ΔSCC |
|---|---:|---:|
| 0 | 0 | +0.044 |
| 0 | 2 | −0.002 |
| 1 | 0 | +0.004 |
| 1 | 2 | +0.055 |

均值 +0.025，SD 0.028，t≈1.79（n=4，双侧 p≈0.17）→ **方向为正，未达显著**。

## 4. 关键消融结论

### P0

- 完整 P0（hybrid + rank 0.5 + 4×128）SCC 0.374，明显低于 v1 0.428；
- **hybrid readout 是主要负贡献**：改回 sum 恢复约 +0.04 SCC；
- 4×128 grouped sampler 药物多样性不足，8×64 接近 v1；
- 排序损失 rank 0.5 约 −0.02，rank 0.2 跨 seed 不稳定；
- 结论：排序损失暂不作为默认训练目标。

### P1（fold0 / seed0）

| 变体 | SCC | R² |
|---|---:|---:|
| T0 v1 | 0.381 | 0.116 |
| P1 推荐 | **0.430** | **0.177** |
| P1 去掉 target branch | 0.363 | 0.087 |
| P1 共享 pathway + 共享 cls | 0.386 | 0.142 |
| P1 共享 pathway，去掉 target | 0.327 | 0.099 |
| P1 去掉 rank embedding | 0.428 | 0.176 |
| P1 完全去掉 cls_proj | ~0.25–0.31 | — |

- target branch 是 P1 的主要正贡献，但跨 fold/seed 不稳定；
- 共享 pathway embedding 在 quick screen 中不成立；
- 低秩 cls_proj 是必要折中；
- rank embedding 影响可忽略。

## 5. 当前模型定位与后续

| 模型/配置 | 定位 | 状态 |
|---|---|---|
| T0 v1 (`t0.yaml`) | 默认无图基线/兜底教师 | 5 折单 seed 已跑 |
| P0 / P0-lite | 实验开关，不作为默认 | 快速验证完成 |
| P1 (`t0_p1.yaml`) | 最强无图候选 | 快速验证完成，待正式 5 折 |
| T1 | 图教师（主教师候选） | **未实现** |

下一步优先级：

1. **正式验证 P1**：`teacher=t0_p1 split=lco fold=all seed=0/1/2`，20 epochs，test 只评一次；
   报告配对 ΔSCC 的 bootstrap CI / 置换检验。
2. **实现 T1**：在 P1 的 gene-level 输入基础上加 PPI/DTI 图，参数匹配；
   主判据用 LDO/scaffold 上 **T1 vs P1**。
3. **图结构负对照**：随机重连 PPI/DTI 边（保持度分布）后重训 T1；
   若 T1 ≈ random-graph T1，图先验不成立。
4. 若 T1 未显著优于 P1：按计划书 R4 降级，T0/P1 作为主教师，T1 转附录。
