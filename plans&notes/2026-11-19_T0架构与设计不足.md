# T0 教师架构与设计不足（2026-11-19）

- 状态：分析记录（供 T0 迭代 / T1 设计参考）
- 相关代码：`src/kite_drp/models/teacher/t0.py`、`drug_enc.py`、`src/kite_drp/train/features.py`
- 相关配置：`configs/teacher/t0.yaml`、`configs/similarity/h3cdr.yaml`
- 相关结果：`docs/model_cards/teacher-t0.md`、`docs/model_cards/teacher-t0-ablations.md`
- 结论：**T0 的主要瓶颈不是参数量，而是表示层压缩过度、交互层冗余、目标函数与 SCC 不对准。**
  T0 适合定位为“无图强基线/消融对照”；教师侧的差异化应主要由 T1 图结构或蒸馏承担。

## 1. 现有架构

代码：`src/kite_drp/models/teacher/t0.py`。

```text
GE  (1000 通路分数) ─┐
MU  (1000 通路分数) ─┼─ 每个模态独立 PathwayTokenEncoder
CNV (1000 通路分数) ─┘   → [CLS] + top-64 通路 token

邻居 GE 加权均值 ─ Linear(1000→256) → 1 个邻居 token

药物 Morgan(2048) + 靶点基因 EmbeddingBag(16) → z_drug(256)

z_drug 作 query，对全部组学 token 做 cross-attention
→ 拼接 [drug, GE tokens, MU tokens, CNV tokens, neighbor]
→ 2 层 TransformerEncoder（d=256, 4 heads, FFN 1024）
→ z_cell = 所有组学 token 均值；z_drug = drug token + 残差
→ z_pair = z_cell + z_drug
→ 回归头 + 分类头（各 256→128→1）
```

关键超参（`configs/teacher/t0.yaml`）：

| 项 | 值 |
|---|---|
| `d_model` | 256 |
| `n_heads` / `n_layers` | 4 / 2 |
| `top_k` | 64 |
| `dropout` / `modality_dropout` | 0.1 / 0.05 |
| `use_neighbor` | true（H3CDR top-15，3 轮融合） |
| `use_gin` | false |
| `readout` | sum |
| 参数量 | 4,728,260（≤5M 目标） |

参数分布：

| 模块 | 参数量 |
|---|---:|
| 3 个模态编码器 | 1,540,608（每个 513,536） |
| 药物编码器 | 1,020,864 |
| TransformerEncoder | 1,579,520 |
| Cross-attention | 263,168 |
| 邻居投影 | 256,256 |
| 回归/分类头 | 66,050 |
| 其他 | ~2,000 |

每个模态编码器里，`pathway_embedding` 是 1000×256≈256k，`cls_proj` 也是 1000×256≈256k；
**一半以上参数在“通路 ID 表”和“全通路线性摘要”上**，而不是在药物-细胞交互上。

## 2. 设计不足

### 2.1 表示层：药物是基因级，细胞是通路级（最根本）

- 药物侧靶点是 **18,396 个基因 ID** 的嵌入；
- 细胞侧输入是 **1,000 个通路分数**，MU 是“通路内 driver 突变基因占比”，CNV 是通路平均；
- 两者没有共享的基因空间，模型只能靠 286 个药物、716 个细胞的数据去“猜”通路和靶点的对应关系。

这会直接削弱靶向药场景：EGFR 突变 vs EGFR 抑制剂、ERBB2 扩增 vs HER2 药物，
在通路平均后可能和别的通路异常看起来一样。T0 把 GE/MU/CNV 都压成 1,000 维通路分数，
是为了参数和速度，但**丢掉了基因身份这一最关键的特权信息**。

### 2.2 token 设计：CLS 与通路 token 没有类型区分

`PathwayTokenEncoder.forward`：

```python
stacked = torch.cat([cls, tokens], dim=1) + self.type_embedding
```

`type_embedding` 是**每个模态一个向量**，被加到 CLS 和所有通路 token 上：

- 模型知道“这是 GE 模态”；
- 但不知道“这是 CLS”还是“第 37 号通路 token”；
- CLS 只能靠内容（全通路线性投影）与通路 token 区分。

标准做法是分别加 `cls_token`、`token_type_embedding`（CLS / pathway / neighbor）和 modality embedding。
当前设计会让 CLS 的读取信号变弱。

### 2.3 三个模态各自一套 pathway embedding，参数冗余

同一个通路 ID 在 GE/MU/CNV 里各有一套 256 维嵌入，合计 768k 参数。
通路语义在三个模态间是共享的，更合理的做法是：

- 共享一份 `pathway_embedding`；
- 每个模态只加 modality-specific projection/bias；
- 或用低秩因子分解。

在只有 716 个细胞的数据规模下，三套 ID 表既增加参数，又降低每个模态的样本效率。

### 2.4 top-k 选择不可微，且输入尺度不统一

- `indices = scores.abs().topk(k)` 是**不可微的硬选择**；哪些通路人选在训练中会跳变，
  梯度只能流过被选中的分数。
- top-k 按绝对值选，不看生物学重要性，也不看正负号；token 里虽带符号分数，
  但“为什么选它”没有约束。
- GE 是 z-score，MU 是 [0,1] 比例，CNV 是 z-score；三个模态的 `score_proj` 结构相同，
  但没有输入标准化，优化尺度不一致。
- top-k 的顺序没有 positional encoding，Transformer 是置换不变的；
  排名信息只靠标量分数和“是否入选”表达。

### 2.5 读出层：mean pooling + sum，缺少显式药物-细胞交互

```python
z_cell = encoded[:, 1:].mean(dim=1)   # 196 个 token 的均值
z_drug = encoded[:, 0] + drug0
z_pair = z_drug + z_cell
```

问题：

- 196 个 token 包括 3 个 CLS、192 个通路 token、1 个邻居 token；
  **mean 会被数量占多数的通路 token 主导**，CLS 信号被稀释。
- 没有 attention pooling / gated pooling / CLS readout。
- `z_pair = z_cell + z_drug` 是加法读出，回归头是 MLP；
  **没有 B0 那种点积式乘性交互**。药敏本质是“药物 × 细胞状态”的交互，
  加法 + MLP 的归纳偏置偏弱。
- 代码支持 `readout=bilinear`，但 fold0 调参时表现不如 sum；
  说明当前实现下乘性读出没有被调好，不代表方向错误。

### 2.6 Cross-attention 冗余，且不可解释

当前流程：

1. drug token 作 query 对组学 token 做一次 cross-attention；
2. 把 cross-attention 结果残差加回 drug token；
3. 再把 drug token 和同一批组学 token 一起送进 self-attention。

问题：

- self-attention 本来就能学 drug-cell 交互，前面的 cross-attention 块**高度冗余**；
- 只有 drug→cell 单向，没有 cell→drug、门控、多 query；
- `need_weights=False`，注意力权重被丢弃，**无法做药物-通路/靶点解释**；
- 计划书里的“可解释蒸馏”在 T0 上没有落地基础。

### 2.7 缺失模态处理不完整

- CNV 有 `cnv_mask`，缺失时用**同一个 missing vector 重复 65 次**
  （1 个 CLS + 64 个 token）。M-716 里 207/716 个细胞 CNV 缺失，
  这些细胞会看到 65 个完全相同的常量 token，扭曲 self-attention 和 mean pooling。
- GE/MU 没有推理期缺失 mask：`_maybe_drop` 只在 `self.training` 时生效；
  如果外部数据缺 GE/MU，模型会把零向量当成真实信号。
- 模态 dropout 只有 0.05，对缺失鲁棒性的正则很弱。

### 2.8 相似性集成太弱

- 邻居 token 是“邻居 GE 通路分数的加权平均”，再过一个 `Linear(1000→256)`；
  细胞自己的 GE 也过 `cls_proj(1000→256)`。**两个 token 高度冗余**，
  邻居 token 只是自己 GE 的平滑版。
- 没有图传播、多跳、邻居标签/边特征；相似性只影响一个 token。
- 没有距离阈值/abstention：即使 query 细胞离所有 train 锚点都很远，
  也会强行取 top-15 并归一化，OOD 时可能注入误导上下文。
- 药物 Tanimoto 相似性已实现，但 T0 **完全没用**。
- 5 折消融：去邻居 ΔSCC −0.013（p=0.37）、ΔR² −0.008（p=0.66），
  **不显著**，与“集成太弱”的判断一致。

### 2.9 药物编码器的信息损失

- Morgan 2048 位是哈希指纹，MLP 590k 参数；286 个药物下容易记住药物 ID。
- 靶点用 `EmbeddingBag(mode="mean")`：一个药物的多个靶点被平均，
  **丢失靶点共现、亲和力、选择性**；无靶点药物得到零向量。
- 没有剂量、DTI/激酶家族、药物-药物相似性图。
- GIN 可选，但单折筛查 +0.88M 参数没有收益（SCC 0.379 vs 0.391）；
  当前 GIN 只是简单 mean-pool，没有 virtual node / attention readout，
  不能据此否定分子图方向。

### 2.10 目标函数与评估不对准

- 主终点是 **SCC**，但损失是 Huber + BCE，**没有排序 / pairwise 损失**。
  模型在优化点误差，不是在优化“同一药物下细胞间的排序”。
- 早停用 val SCC，最后又报告同一个 val SCC；**test 完全没动**。
  这是乐观估计，论文里应报告 test。
- 单 seed；5 折在同一进程内顺序训练，fold 间共享 RNG 状态；
  p 值未做多重比较校正。
- 没有温度校准 / Platt scaling，ECE 只是被动报告。

### 2.11 容量与数据量不匹配

4.73M 参数、108k train pairs、716 个细胞、286 个药物；
细胞/药物级别的有效样本很少。消融里：

- GE-only 3.70M 与 full 4.73M 在 5 折上无显著差异
  （SCC 0.438 vs 0.427，p=0.53）；
- 完整 T0 与 B0 也无显著差异（SCC 0.427 vs 0.440，p=0.27）；
- 很多变体在 epoch 0–3 就早停。

说明当前容量里**有大量参数没有转化为可泛化的交互能力**，
更多是在拟合静态 ID / 模态噪声。

## 3. 已被实验证实的不足

| 设计点 | 证据 | 判断 |
|---|---|---|
| 多组学增益 | 去 MU：ΔSCC −0.002（p=0.85）；GE-only：ΔSCC +0.011（p=0.53） | 教师精度上无显著增益 |
| 交叉注意力结构 | T0 vs B0：ΔSCC −0.013（p=0.27） | 未显著优于双线性 |
| 邻居 token | 去邻居：ΔSCC −0.013（p=0.37） | 方向为正但不显著 |
| GIN | fold0：SCC 0.379 vs 0.391，+0.88M 参数 | 当前实现不值得 |
| 其余（token 类型、mean pooling、排序损失、缺失模态） | 尚无针对性消融 | 结构性假设，需要实验确认 |

因此论文里不能把 T0 的卖点写成“多组学 + 注意力 + 相似性带来增益”；
目前数据不支持。**T0 更适合定位为无图强基线/消融对照，主教师需要 T1 的图结构或蒸馏来体现差异化。**

## 4. 修改优先级

### P0（便宜、直接对准当前问题）

1. **加排序损失**：Huber + pairwise ranking（同药物内 cell 对，或同细胞内 drug 对），
   直接优化 SCC；这是最可能改变主指标的改动。
2. **修 token 类型与读出**：独立 CLS token、token-type embedding；
   用 CLS readout 或 attention pooling 替代 mean；
   `z_pair` 改为 `[z_cell, z_drug, z_cell*z_drug]` 的混合读出。
3. **缺失模态 mask**：GE/MU 也传 availability mask；缺失时整段 modality token 丢弃，
   而不是重复 missing vector；模态 dropout 提到 0.1–0.2。
4. **评估协议**：test 只报告一次；逐折 `set_seed(seed+fold)`；至少 3 seeds。

### P1（结构层面）

5. **共享 pathway embedding**：一份 1000×256 + 模态投影，省 ~0.5M 参数，提升样本效率。
6. **加强相似性**：不要只加一个邻居 token；用 cell-cell 图传播、
   similarity-biased attention 或邻居 embedding 残差；加距离阈值/abstention。
7. **药物-细胞共享基因空间**：为药物靶点基因注入细胞侧 gene-level token
   （表达/突变/CNV），或做 target-aware cross-attention；
   这是解决“药物基因级、细胞通路级”错配的关键。
8. **cross-attention 改造**：双向/门控、多 query，或直接用 attended drug token
   作为 pair 表示；打开 attention weights 做解释。

### P2（T1 及后续）

9. T1 异构图：gene 节点 + PPI/DTI 边 + 细胞相似性边 + 药物 GIN；
   把相似性放到图里验证，而不是 T0 的单 token。
10. 药物侧补 DTI/亲和力、药物相似性；GIN 在 T1 里重新评估。
11. 校准、不确定性、LDO/scaffold 与 unseen-drug 回退。

## 6. 一句话总结

**T0 的架构是“通路 token 化的无图交叉注意力”，工程上完整，
但表示层把基因级信息压得太狠、交互层有冗余、读出层和损失函数没有对准药敏排序；
当前消融也证实多组学/注意力/邻居 token 都没有显著增益。**

如果目标是把教师做出差异化，优先做 P0 的排序损失和读出修复，
然后把主要精力放到 T1 的基因级异构图。
