# `plans&notes/` —— Agent 生成的计划与过程文档

本目录存放**由 AI Agent 生成/维护**的计划书、调研笔记、执行记录与决策依据。
人读的长期文档（ADR、数据卡、模型卡、环境文档等）放 `docs/`，两者不要混用。

## 约定

1. **文件命名**：`YYYY-MM-DD_<主题>.md`（如 `2026-11-15_仓库结构与工程配置说明.md`）；
   项目主计划书等长期活文档可保留固定名称。
2. **内容边界**：
   - 计划书/技术方案、Agent 任务拆解、执行记录、变更说明；
   - 调研笔记、文献笔记、数据审计记录；
   - **不写**密钥、患者信息（PHI）、受限数据内容；不粘贴大段受版权保护原文。
3. **与 `docs/` 的分工**：需要长期维护、被代码/论文引用的产物（ADR、数据卡、模型卡、
   泄漏审查表、环境文档）在 `docs/`；本目录记录其"由来与过程"。
4. **变更记录**：重大结构调整先写本目录说明，再同步 `docs/adr/`。
