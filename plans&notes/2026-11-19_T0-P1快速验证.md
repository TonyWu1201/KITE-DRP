# T0 P1 改动与快速验证（2026-11-19）

- 分支：`feat/t0-p1-target-gene`（基于 `feat/t0-p0-ranking-readout`，P0 尚未合入 master）
- 范围：P1 结构（target-aware gene branch / cls_proj 低秩化 / 共享 pathway 开关）
- 状态：代码已落地；快速验证为 **2 折 × 2 seeds × 5 epochs**，不是最终论文结果
- 相关配置：`configs/teacher/t0_p1.yaml`
- 相关代码：`src/kite_drp/models/teacher/t0.py`、`src/kite_drp/train/features.py`、`src/kite_drp/train/data.py`

## 1. 动机

`plans&notes/2026-11-19_T0架构与设计不足.md` §2.1 指出：药物侧是 **18,396 个靶点基因 ID**，
细胞侧只有 **1,000 维通路分数**，两者没有共享的基因空间。靶向药场景下，
EGFR 突变 vs EGFR 抑制剂、ERBB2 扩增 vs HER2 药物在通路平均后可能难以区分。

P1 的目标不是再加一个通路 token，而是让模型直接看到“这个药物的靶点基因，
在当前细胞里表达/突变/CNV 是什么状态”。

## 2. 已实现

### 2.1 逐基因细胞特征

`build_cell_features` 新增与 GE 基因顺序一致的逐基因矩阵：

| 字段 | 形状 | 说明 |
|---|---|---|
| `gene_ge` | (716, 18,396) | fold 内 z-score |
| `gene_mu` | (716, 18,396) | MU_B driver 突变 0/1；非 panel 基因为 0 |
| `gene_cnv` | (716, 18,396) | fold 内 z-score；CNV 缺失细胞整行 0 |
| `gene_ge_valid` / `gene_cnv_valid` | (18,396,) | fold scaler 的基因有效性 |
| `gene_mu_available` | (18,396,) | 是否在 MU panel 中 |

所有矩阵都按 GE 基因顺序对齐；`drug_features.npz` 的 `target_genes` 与
`teacher_index.json` 的 `ge_genes` 顺序一致（构建时校验）。

### 2.2 每对 (drug, cell) 的靶点基因表

`build_pair_tensors` 为每个药物建立靶点基因表：

- 把药物靶点索引映射到细胞基因位置；
- 每个药物最多保留 `target_max_tokens=64` 个靶点（99% 药物 ≤106，只有极少数多靶点药物被随机截断；
  固定种子、可复现）；
- `collate_pairs` 按 `(cell, drug)` 向量化 gather，输出：
  - `target_gene_ids` (B, T)
  - `target_gene_values` (B, T, 2×M)：每个模态的值 + availability flag
  - `target_gene_mask` (B, T)

`target_modalities` 跟随启用的模态，因此后续做 GE-only / GE+CNV 等模态消融时，
target branch 不会偷偷看到被禁用的模态。

### 2.3 TargetGeneEncoder

`TargetGeneEncoder`：

1. 基因 ID 嵌入 `Embedding(18,396, 16)`，与药物编码器的 `EmbeddingBag` **共享同一张权重表**；
2. 靶点值投影 `Linear(2×M, 256)`；
3. 1 层 TransformerEncoder 建模靶点间关系（可关）；
4. 带 mask 的 attention pooling → 1 个 target token；
5. `target_gate` 初始为 0（`tanh` 门控），target branch 从“无贡献”开始学习。

target token 与 GE/MU/CNV/邻居 token 一起送入 cross-attention 和 self-attention；
无靶点药物（49/286）的 target token 被 mask。

### 2.4 cls_proj 与 pathway 嵌入开关

`T0Teacher` 新增：

- `cls_proj_mode`：`full`（v1 每模态 1000→256）/ `shared`（三模态共用一份）/
  `lowrank`（三模态共用 1000→64→256）/ `none`（可学习 CLS）；
- `shared_pathway`：三模态共享一份 1000×256 pathway embedding；
- `shared_pathway_proj`：共享表 + 每模态 256→256 残差投影。

最终 `t0_p1.yaml` 采用 **独立 pathway 表 + 低秩 cls_proj**，参数 4,889,862（≤5M）。

## 3. 快速验证协议

| 项 | 设置 |
|---|---|
| split | `p1_lco_s0` |
| folds | 0, 2 |
| seeds | 0, 1 |
| epochs | 5 |
| patience | 5 |
| batch | 512 |
| 指标 | val R² / SCC / AUROC / per-drug SCC |

| 组件对照 | P1 去掉 target branch（`teacher.target_branch=false`） |

> 2 折 × 5 epoch 的方差很大；以下只用于筛选方向，不作为最终结论。

## 4. 主结果（2 seeds × 2 folds = 4 个观测）

| 变体 | 参数 | R² | SCC | AUROC | per-drug SCC |
|---|---:|---:|---:|---:|---:|
| T0 v1 | 4,728,260 | 0.156 ± 0.049 | 0.415 ± 0.054 | 0.700 ± 0.024 | 0.411 ± 0.052 |
| **T0 P1** | 4,889,862 | **0.170 ± 0.054** | **0.440 ± 0.062** | **0.710 ± 0.031** | **0.436 ± 0.057** |
| P1 去掉 target branch | 4,092,677 | 0.114 ± 0.061 | 0.417 ± 0.051 | 0.702 ± 0.025 | 0.411 ± 0.046 |
| P0-lite（前一轮） | 4,780,741 | 0.166 ± 0.045 | 0.410 ± 0.049 | 0.698 ± 0.022 | 0.405 ± 0.047 |

P1 相对 v1：**ΔSCC +0.025、ΔR² +0.014、ΔAUROC +0.009、Δper-drug SCC +0.025**。

逐 (seed, fold) 的 ΔSCC：

| seed | fold | ΔSCC (P1 − v1) |
|---|---:|---:|
| 0 | 0 | +0.044 |
| 0 | 2 | −0.002 |
| 1 | 0 | +0.004 |
| 1 | 2 | +0.055 |

均值 +0.025，SD 0.028，SE 0.014，t≈1.79（n=4，双侧 p≈0.17）。
**方向为正，但 4 个观测不足以宣称显著。**

## 5. 组件消融

### 5.1 fold0 / seed0（5 epochs）

| 变体 | SCC | R² | 说明 |
|---|---:|---:|---|
| T0 v1 | 0.381 | 0.116 | 参照 |
| P1（独立 pathway + 低秩 cls + target） | **0.430** | **0.177** | 推荐 |
| P1 去掉 target branch | 0.363 | 0.087 | target branch 贡献约 +0.065 SCC |
| P1 共享 pathway + 共享 cls | 0.386 | 0.142 | 共享 pathway 明显低于独立表 |
| P1 共享 pathway，去掉 target | 0.327 | 0.099 | 共享 pathway 本身也掉点 |
| P1 去掉 rank embedding | 0.428 | 0.176 | 与保留几乎相同 |
| P1 完全去掉 cls_proj | ~0.25–0.31 | — | 早期试验，明显掉点 |

### 5.2 结论

1. **target-aware gene branch 是 P1 的主要正贡献**：4 个观测平均 +0.023 SCC，
   但跨 fold/seed 不稳定（t≈0.91）。
2. **共享 pathway embedding 在 quick screen 中不成立**：fold0 从 0.430 降到 0.386；
   三套模态 ID 表虽然参数多，但在 716 个细胞规模下提供了有用的模态特异性。
3. **cls_proj 不能直接删**：完全去掉后 fold0 掉到 ~0.25–0.31；低秩共享投影
   （1000→64→256）能保留全局摘要并把参数从 3×256k 降到 80k。
4. **top-k rank embedding 影响可忽略**：保留与否 ΔSCC <0.002。
5. **P1 与 P0-lite 的差异主要来自 target branch**：P1 0.440 vs P0-lite 0.410。

## 6. 复现

```bash
# P1 推荐配置
uv run python -m kite_drp.train.teacher_train teacher=t0_p1 split=lco fold=all seed=0

# 2 折 × 2 seeds 快速对照
uv run python scripts/run_ablations.py \
  --only t0_full,t0_p1,t0_p1_notarget \
  --folds 0,2 --seed 0 --epochs 5 --patience 5 --workers 1
uv run python scripts/run_ablations.py \
  --only t0_full,t0_p1,t0_p1_notarget \
  --folds 0,2 --seed 1 --epochs 5 --patience 5 --workers 1
```

## 7. 限制

- 只跑 LCO fold 0/2、5 epoch；未跑 5 折 × 20 epoch × 3 seeds，也未评 test。
- 早停和报告都用 val SCC，指标偏乐观；未做 BH-FDR。
- 靶点表在超过 64 个靶点时做固定随机截断；未评估不同 cap / 采样策略。
- 逐基因值只做了 fold 内 z-score / 0-1，没有基因级归一化或缺失插补。
- 未做 GE-only / GE+CNV / 无 MU 等模态消融；target values 已按启用模态裁剪。
- 未评估靶点基因 token 的可解释性（attention 权重只作为辅助输出）。
