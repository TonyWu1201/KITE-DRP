# T0 P0 改动与快速验证（2026-11-19）

- 分支：`feat/t0-p0-ranking-readout`
- 范围：P0（排序损失 / token-readout / 缺失 mask / 逐折 seed）
- 状态：代码已落地；快速验证为 **2 折 × 2 seeds × 5 epochs**，不是最终论文结果
- 相关：`configs/teacher/t0_p0.yaml`（完整 P0）、`configs/teacher/t0_p0_lite.yaml`（推荐落点）、`docs/model_cards/teacher-t0.md`

## 1. 已实现

1. **同药物 pairwise ranking loss**（`src/kite_drp/train/losses.py`）：
   - 同药物内按标签差加权，`softplus(-(s_i-s_j)·sign(y_i-y_j)/τ)`；
   - 支持 mask、最小标签差、每组最多 pair 数。
2. **drug-balanced batch sampler**（`src/kite_drp/train/data.py`）：
   - 每个 epoch 将每个药物的全部训练 pair 拆成 chunk，覆盖完整训练集；
   - 避免旧实现“每药每 epoch 只取一个 chunk”导致实际训练量只有 v1 的 1/3。
3. **token/readout 修复**：
   - 独立 CLS / pathway / drug token type；
   - top-k rank embedding；
   - masked attention pooling 替代 196-token mean；
   - `readout=hybrid`（`[z_cell, z_drug, z_cell*z_drug]` + 显式双线性项）。
4. **缺失模态**：
   - GE/MU/CNV availability mask；
   - 缺失模态整段 token 用 key padding mask 屏蔽，不再重复 missing vector；
   - modality dropout 0.15；
   - presence vector。
5. **训练/评估协议**：
   - 逐折 `set_seed(seed*100+fold)`；
   - 可选 EMA（quick screen 中关闭，5 epoch/72 步下明显滞后）；
   - per-drug SCC、test 单次评估入口；
   - `train.ema_decay`、`train.min_epochs`、`train.eval_test` 等配置项。

## 2. 快速验证协议

| 项 | 设置 |
|---|---|
| split | `p1_lco_s0` |
| folds | 0, 2 |
| seeds | 0, 1 |
| epochs | 5 |
| patience | 5 |
| batch | 512 |
| 指标 | val R² / SCC / AUROC / per-drug SCC |

> 2 折 × 5 epoch 的方差很大；以下只用于筛选方向，不作为最终结论。

## 3. 主结果（2 seeds × 2 folds = 4 个观测）

| 变体 | 参数 | R² | SCC | AUROC | per-drug SCC |
|---|---:|---:|---:|---:|---:|
| T0 v1 | 4,728,260 | 0.155 | **0.414** | **0.701** | **0.409** |
| P0-lite（sum, no-rank, 8×64） | 4,780,741 | **0.166** | 0.410 | 0.698 | 0.405 |
| P0-lite + rank 0.2（8×64） | 4,780,741 | 0.132 | 0.403 | 0.697 | 0.401 |

P0-lite 相对 v1：ΔSCC −0.004、ΔR² +0.011、ΔAUROC −0.002。
**SCC 基本打平，R² 略好；没有达到“提升 SCC”的 P0 目标。**

## 4. 组件消融（seed0, 2 folds, 5 epochs）

| 变体 | SCC | 说明 |
|---|---:|---|
| T0 v1 | 0.428 | 参照 |
| 完整 P0（hybrid + rank 0.5 + 4×128） | 0.374 | 明显下降 |
| P0 sum readout（4×128） | 0.416 | **hybrid 是主要负贡献** |
| P0 no-rank（hybrid, 4×128） | 0.383 | rank 之外，hybrid 仍拖累 |
| P0 mean pooling（hybrid, 4×128） | 0.377 | attention pooling 不是主因 |
| P0 dropout 0.05（hybrid, 4×128） | 0.383 | dropout 0.15 不是主因 |
| v1 + grouped 4×128（无 rank） | 0.397 | 4×128 的 batch 药物多样性不足 |
| v1 + grouped 8×64（无 rank） | 0.408 | 8×64 缓解，但仍低于 v1 |
| v1 + rank 0.2（4×128） | 0.416 | 排序损失小幅负贡献 |
| P0-lite std sampler（seed0） | 0.420 | 与 8×64 接近 |

## 5. 结论

1. **完整 P0 不建议启用**：hybrid readout + 4×128 grouped sampler + rank 0.5 组合明显低于 v1。
2. **hybrid readout 是最大问题**：当前实现下 `pair_proj + 直接双线性项` 在 5 epoch 内优化困难；sum readout 恢复约 +0.04 SCC。
3. **grouped sampler 需要足够药物多样性**：4 drugs × 128 cells 掉约 −0.03；8 drugs × 64 cells 接近 v1。
4. **排序损失没有显示稳定增益**：rank 0.5 约 −0.02；rank 0.2 在 seed0 略负、seed1 略正，跨 seed 不稳定。当前实现不足以支持“排序损失提升 SCC”的结论。
5. **P0-lite 是当前更合理的落点**：sum readout、无 rank、8×64、token types/masks/attention；SCC 与 v1 打平，R² 略好，可作为“缺失模态更稳健”的基线，但不能宣称精度提升。
6. 下一步若仍要提升 T0 主指标，优先做 **P1 target-aware gene branch**（靶点基因的细胞 GE/MU/CNV token），而不是继续调 rank 权重；图结构/相似性仍留给 T1。

## 6. 复现

```bash
# P0-lite 推荐配置
uv run python -m kite_drp.train.teacher_train teacher=t0_p0_lite split=lco fold=all seed=0

# 完整 P0（实验开关）
uv run python -m kite_drp.train.teacher_train teacher=t0_p0 split=lco fold=all seed=0

# 快速对照（2 folds x 2 seeds）
uv run python scripts/run_ablations.py \
  --only t0_full,t0_p0_sum_no_rank_8x64,t0_p0_sum_rank02_8x64 \
  --folds 0,2 --seed 0 --epochs 5 --patience 5 --workers 1
uv run python scripts/run_ablations.py \
  --only t0_full,t0_p0_sum_no_rank_8x64,t0_p0_sum_rank02_8x64 \
  --folds 0,2 --seed 1 --epochs 5 --patience 5 --workers 1
```

## 7. 限制

- 只跑 LCO 的 fold 0/2、5 epoch；未跑 5 折 × 20 epoch、LDO/scaffold。
- 未做 BH-FDR；2 折 × 2 seeds 的均值/SD 仅作方向性参考。
- 未评估缺失模态子集（如 CNV-missing cells）的鲁棒性收益；需要后续按 `cnv_mask` 分层报告。
