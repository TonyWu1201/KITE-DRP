## 2. 许可与引用

- 许可：学术引用；再分发待核实（`data/licenses/ding2016.md`）。
- 引用：Ding H, Zu J, Gu X. *Bioinformatics* 2016;32(19):2891–2899。

## 3. 内容与口径

- 10 个有表头列 + 4 个无表头补充列；无剂量/周期。
- **CESC 使用全称标签** `Cervical squamous cell carcinoma and endocervical adenocarcinoma (CESC)`；按缩写过滤会得 0 行。
- CESC 97 条 / 69 例 / 12 药；**Cisplatin 62 条 / 59 例**（CR 47、PD 8、PR 5、SD 2）。
- 响应映射：CR+PR → 敏感（1）；PD+SD → 耐药（0）；其余 NA。
- 顺铂严格响应者 52/62（83.9%），严重不平衡。

## 4. 预处理

- 脚本：`src/kite_drp/data/tcga.py`。
- 产物：`data/interim/canonical/tcga_ding2016.parquet`。
- 仅评估，不参与训练/选模/早停。

## 5. 已知缺陷与风险

- 标签是 TCGA 自由文本治疗结局的再整理，非独立 RECIST 复核。
- 无剂量/周期；易与 clinical 的治疗记录混淆（clinical 顺铂 128 例 ≠ Ding 59 例）。
- CESC 仅顺铂达到 n≥30；其他药只做描述性分析。
- CR 占比高，AUROC 需配合 AUPRC 与 bootstrap CI。

## 6. 使用计划

- L2：Cisplatin-CESC 二分类弱标签（n=59），只评估。
- 敏感性分析：CR/PR vs PD/SD 的不同定义。
- 与 clinical `treatment_outcome` 交叉 QC，不混用。
