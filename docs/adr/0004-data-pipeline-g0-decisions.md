# ADR-0004：G0 数据管线实现口径与两处实测偏差

- 状态：已接受
- 日期：2026-11-17
- 相关：`plans&notes/2026-11-17_数据预处理详细规划.md` v1.1 §3.3/§3.4/§4.1–§4.4/§5；D20–D31

## 背景

G0 管线首次落地时，对本地 `data/raw/` 做了全量实测。规划 v1.1 的多数契约可以直接实现，
但有两处"规划数字"与原始文件实际结构不一致，必须记录以便论文/报告口径一致：

1. **CNV 有效基因数**：规划写"删 811 个全 NaN 列 → 19,144 基因；U_teach_ge=19,125"。
   实测 811 个全 NaN 列中有 **753 个是可解析的 `SYMBOL (ENTREZ)` 列**；删除后
   CNV 可解析且非全 NaN 的基因是 **18,613**，不是 19,144。剩余 531 个非标准列（裸 ENSG）
   在本机 HGNC 快照中无对应项，无法安全映射。
2. 因此 `U_teach_ge = 19,210（GE 去 5 个全局零方差）∩ 18,613 = 18,396`，而不是 19,125。
   主池 **M-509 不受影响**（GDSC∩GE∩MU∩CNV 仍为 509，标签对 126,803）。

## 选项

1. **按规划数字硬编码 19,125**：需要把 753 个全 NaN 基因列纳入宇宙并保留 NaN/mask。
   优点：与规划文本一致；缺点：引入 753 个不可训练维度，违背"CNV 无 NaN"校验，
   且 `U_vae`/教师编码器会包含无观测基因。
2. **按实测 18,396 落盘**：只保留有观测的基因；在 manifest/质量报告/ADR 记录偏差。
   优点：数据真实、可训练、可复现；缺点：与规划正文数字不同，论文需说明。

## 决策

选择 **2**：以构建脚本从 raw 计算的实测维度为准，禁止硬编码 19,125；
`data/interim/canonical/manifest.json`、`gene_universes.json` 与质量报告记录实际维度。
同时按 v1.1 的其余契约实现：

- **D31**：教师 MU 默认 **B（LikelyLoF/Hotspot）**；学生 panel 默认 **A（非沉默）**，两者都产出。
- **M-716 教师矩阵**：`teacher_inputs.npz` 行 = M-716（GE+MU），CNV 对 207 株缺失，
  以 `cnv_observed_mask` 标记；M-509 是子集。取消无统计意义的 M-513 档。
- **CNV 裁剪移入 fit_stats**：canonical 保留 log2 原值；每个 fold 在训练细胞系上估计
  [0.1, 99.9] 分位并写 `fit_stats/.../cnv_clip.json`。
- **突变负荷**：不再除以 30 Mb 冒充 TMB；输出 `mut_burden_A/B`（官方预筛后的突变基因数）。
- **U_panel 兜底**：外部 panel 缺失时，在 **fit_stats 内**按训练 fold 的突变携带率选基因，
  写 `panel_genes.json`；processed 的学生 panel 作为候选全集。
- **P3**：SMILES/RDKit 缺失时降级为 target-family split，JSON 中 `degraded=true` 并写 notes。

## 后果

- 正面：所有维度可由 raw 一键重建；无静默 NaN 维度；泄漏边界清晰。
- 负面：与规划正文的 19,125/19,144 数字不一致，论文/数据卡必须引用本 ADR 与 manifest。
- 后续：若补齐 HGNC 旧 ENSG 映射或改用 DepMap 官方 CNV 矩阵，可重新评估宇宙；
  届时新增 split/产物版本，不原地修改已冻结文件。
